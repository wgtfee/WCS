# 多协议工业通信架构

## 概述

本架构为 WCS 系统提供统一的 PLC/设备通信抽象层，支持以下工业协议，每种协议均使用行业标准开源库实现：

| 协议 | 用途 | 底层库 |
|------|------|--------|
| **Modbus TCP** | 通用 PLC、传感器、仪表 | [NModbus](https://www.nuget.org/packages/NModbus/) |
| **OPC UA** | 高端 PLC、跨平台数据交换 | [OPC Foundation 官方库](https://www.nuget.org/packages/OPCFoundation.NetStandard.Opc.Ua.Client/) |
| **EtherNet/IP** | Allen-Bradley / Rockwell PLC | Socket (生产环境推荐 [libplctag](https://www.nuget.org/packages/libplctag/)) |
| **MQTT** | 物联网设备、消息推送 | [MQTTnet](https://www.nuget.org/packages/MQTTnet/) |
| **S7 (Siemens)** | Siemens S7 PLC | Snap7（已有实现，保持兼容） |

---

## 架构设计

```
PlcSubsystem/
├── Abstractions/                    ← 统一接口 + 枚举 + 状态模型
│   ├── IPlcConnection.cs           ← 核心接口
│   ├── PlcProtocolType.cs          ← 协议枚举
│   └── PlcConnectionStatus.cs      ← 连接状态
├── PlcConnectionBase.cs             ← 抽象基类（状态管理 / 日志 / 计数器）
├── PlcConnectionFactory.cs          ← 工厂：根据配置创建对应协议实例
├── PlcRegistrationExtensions.cs     ← DI 注册扩展
│
├── Modbus/
│   └── ModbusConnection.cs          ← NModbus TCP
├── OpcUa/
│   └── OpcUaConnection.cs           ← OPC Foundation 客户端
├── Eip/
│   └── EipConnection.cs             ← TCP Socket（可用 libplctag 替代）
├── Mqtt/
│   └── MqttConnection.cs            ← MQTTnet 发布/订阅
└── S7/
    ├── S7Connection.cs              ← 模拟实现（向后兼容）
    └── ...                          ← 其他 S7 配套
```

### 核心接口 `IPlcConnection`

所有协议实现同一接口，可无缝替换：

```csharp
public interface IPlcConnection : IDisposable
{
    string Name { get; }                          // 连接名称
    PlcProtocolType ProtocolType { get; }         // 协议类型
    bool IsConnected { get; }                     // 是否已连接

    Task<bool> ConnectAsync(CancellationToken ct = default);
    Task<bool> DisconnectAsync(CancellationToken ct = default);
    Task<byte[]?> ReadAsync(string address, ushort length, CancellationToken ct = default);
    Task<bool> WriteAsync(string address, byte[] data, CancellationToken ct = default);
    PlcConnectionStatus GetStatus();
}
```

### 抽象基类 `PlcConnectionBase`

所有协议实现继承此类，自动获得：

- 连接状态机管理（`Connected` / `Failed` / `Disconnected`）
- 读写计数器 + 心跳时间戳
- 失败计数 + 错误日志
- 线程安全的状态快照

## 各协议使用说明

### 1. Modbus TCP（NModbus）

**配置**：
```csharp
var config = new ModbusConnectionConfig
{
    Name = "生产线PLC1",
    Host = "192.168.1.100",
    Port = 502,
    UnitId = 1,        // 从站地址
    TimeoutMs = 5000,
};
```

**地址格式**：
| 类型 | 格式 | 示例 |
|------|------|------|
| 保持寄存器 | `HR:{起始地址}` | `HR:0` 读取保持寄存器 0 |
| 输入寄存器 | `IR:{起始地址}` | `IR:0` 读取输入寄存器 0 |
| 线圈 | `COIL:{起始地址}` | `COIL:0` 写入线圈 0 |

**使用示例**：
```csharp
var conn = new ModbusConnection(config, logger);
await conn.ConnectAsync();

// 读取 10 个保持寄存器 (地址 HR:0)
var data = await conn.ReadAsync("HR:0", 10);
// 返回 byte[20] (10个ushort × 2字节，大端序)

// 写入 4 个保持寄存器 (地址 HR:100)
var writeData = new byte[] { 0x00, 0x64, 0x00, 0xC8 };
await conn.WriteAsync("HR:100", writeData);

await conn.DisconnectAsync();
```

### 2. OPC UA（OPC Foundation）

**配置**：
```csharp
var config = new OpcUaConnectionConfig
{
    Name = "OPCUAServer1",
    EndpointUrl = "opc.tcp://192.168.1.200:4840",
    UseSecurity = false,       // 测试环境可关闭安全
    TimeoutMs = 10000,
};
```

**地址格式**：使用 OPC UA 节点 ID 字符串，如 `ns=2;s=MyVariable`

**使用示例**：
```csharp
var conn = new OpcUaConnection(config, logger);
await conn.ConnectAsync();

// 读取节点值
var value = await conn.ReadAsync("ns=2;s=Temperature", 4);
// 返回 byte[]，自动将 int/float/bool 转为字节

// 写入节点值（默认按 int 写入）
await conn.WriteAsync("ns=2;s=SetSpeed", BitConverter.GetBytes(1500));

// 断开连接
await conn.DisconnectAsync();
```

> **注意**：OPC UA 支持更丰富的数据类型，`ReadAsync` 自动将 int/uint/short/
> float/double/bool/string 转为 `byte[]`，若需精确类型控制可直接访问 `Session` 属性。

### 3. EtherNet/IP（TCP Socket）

**配置**：
```csharp
var config = new EipConnectionConfig
{
    Name = "AB_PLC",
    Host = "192.168.1.50",
    Port = 44818,
    TimeoutMs = 5000,
};
```

> **生产建议**：当前实现基于 TCP Socket 进行基础 CIP 通信。
> 生产环境推荐使用 [libplctag](https://www.nuget.org/packages/libplctag/) 替代，
> 它原生支持 Allen-Bradley ControlLogix / CompactLogix 等主流 PLC 的标签读写。
>
> ```csharp
> // libplctag 示例（需安装原生运行时）
> using var tag = new Tag
> {
>     Name = "MyTag",
>     Gateway = "192.168.1.50",
>     Path = "1,0",
>     PlcType = PlcType.ControlLogix,
>     Protocol = Protocol.EIP,
>     Timeout = TimeSpan.FromSeconds(5),
> };
> ```

**使用示例**：
```csharp
var conn = new EipConnection(config, logger);
await conn.ConnectAsync();

// 读取标签数据
var data = await conn.ReadAsync("MyTag", 10);

await conn.DisconnectAsync();
```

### 4. MQTT（MQTTnet）

**配置**：
```csharp
var config = new MqttConnectionConfig
{
    Name = "MQTTBroker",
    Host = "mqtt.example.com",
    Port = 1883,
    Username = "wcs",
    Password = "wcs123",
    ClientId = $"WcsCore_{Guid.NewGuid():N}",  // 自动生成唯一客户端ID
    TimeoutMs = 5000,
};
```

**特点**：
- MQTT 是发布/订阅模型，`ReadAsync` 不支持直接读取
- 通过 `SubscribeAsync` + `OnMessageReceived` 事件接收消息
- 通过 `WriteAsync` 按主题发布消息

**使用示例**：
```csharp
var conn = new MqttConnection(config, logger);
await conn.ConnectAsync();

// 订阅主题
conn.OnMessageReceived += (topic, payload) =>
{
    Console.WriteLine($"收到 {topic}: {Encoding.UTF8.GetString(payload)}");
    return Task.CompletedTask;
};
await conn.SubscribeAsync("wcs/commands/#");

// 发布消息
await conn.WriteAsync("wcs/status",
    Encoding.UTF8.GetBytes("{\"status\":\"running\"}"));

// 断开连接
await conn.DisconnectAsync();
```

> **自动重连**：MQTT 连接意外断开时会自动等待 3 秒后重连。

### 5. 工厂模式创建连接

```csharp
[ApiController]
[Route("api/plc")]
public class PlcController : ControllerBase
{
    private readonly PlcConnectionFactory _factory;

    public PlcController(PlcConnectionFactory factory)
    {
        _factory = factory;
    }

    [HttpPost("connect")]
    public async Task<IActionResult> Connect([FromBody] ProtocolConnectionConfig config)
    {
        var conn = _factory.Create(config);
        var ok = await conn.ConnectAsync();
        return Ok(new { ok, status = conn.GetStatus() });
    }
}
```

## DI 注册

```csharp
// Program.cs 或模块注册中
services.AddWcsPlcCore();

// 按需注册具体的 PLC 连接
services.AddPlcConnection(new ProtocolConnectionConfig
{
    Name = "ModbusPLC1",
    Protocol = PlcProtocolType.Modbus,
    Host = "192.168.1.100",
    Port = 502,
});
```

`AddWcsPlcCore()` 注册的服务：

| 服务 | 生命周期 | 说明 |
|------|----------|------|
| `PlcConnectionFactory` | Singleton | 连接工厂 |
| `ModbusConnection` | Transient | Modbus 连接 |
| `OpcUaConnection` | Transient | OPC UA 连接 |
| `EipConnection` | Transient | EIP 连接 |
| `MqttConnection` | Transient | MQTT 连接 |

## 扩展：添加新协议

1. 在 `PlcProtocolType` 枚举中添加新类型
2. 创建 `YourProtocol/YourProtocolConnection.cs` 继承 `PlcConnectionBase`
3. 在 `PlcConnectionFactory.Create()` 中添加创建分支
4. 在 `PlcRegistrationExtensions` 中注册到 DI
5. 在 `_routeMap` 的对应 `ProtocolConnectionConfig` 中添加配置

无需修改现有代码即可扩展新协议。
