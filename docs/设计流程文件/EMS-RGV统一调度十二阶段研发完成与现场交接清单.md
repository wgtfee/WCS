# EMS/RGV 统一调度十二阶段研发完成与现场交接清单

## 1. 状态定义

本文件区分三个不同状态：

### A. 研发阶段完成

表示代码、自动化测试、Host、Desktop 和设计文档已经完成并通过 CI。

### B. 现场联调完成

表示真实 PLC 点位、车辆、路线、站点、闭塞和故障处理已经在现场逐项验证。

### C. 正式投产验收

表示连续生产验证、故障演练、回退演练和多部门签署已经完成。

第十二阶段 CI 通过后，只能确认 **A. 研发阶段完成**，不能自动宣称 B 或 C 已完成。

## 2. 十二阶段能力清单

| 阶段 | 主题 | 主要交付 |
|---|---|---|
| 第一阶段 | 统一调度基础 | EMS/RGV 统一车辆、任务、派单、路线和路权模型 |
| 第二阶段 | 执行闭环 | Load、Move、Unload、Pause、Resume 和位置反馈 |
| 第三阶段 | 交通控制 | 滚动路权、交叉口、等待图、死锁检测与安全解除 |
| 第四阶段 | 持久化恢复 | 车辆、任务、路权、命令快照和重启对账 |
| 第五阶段 | 运行优化 | 电量、充电、故障重分配和 KPI |
| 第六阶段 | 配置治理 | 版本控制、双人审批、权限与审计 |
| 第七阶段 | 真实 PLC 驱动 | 点位映射、命令确认、心跳、状态同步 |
| 第八阶段 | 现场联调 | 点位导入、单点诊断、故障字典、冲突处置与补偿 |
| 第九阶段 | 生产调度 | 任务竞争、站点拥堵、单轨会车、趋势与故障接管 |
| 第十阶段 | 可观测性 | TraceId、OpenTelemetry、Prometheus、三方一致性与健康评分 |
| 第十一步 | 生产韧性 | 生产就绪、逻辑备份、恢复准备和隔离演练 |
| 第十二阶段 | 仿真验收 | 历史回放、A/B、批量优化、拥堵预测、容量基线和最终验收 |

## 3. 现场交接输入

现场联调前必须准备：

- 正式 PLC 程序版本号；
- 正式点位表和 DB/Tag 地址；
- 车辆编号、类型和控制器对应关系；
- 轨道节点、边、方向和距离；
- 单轨区段和物理闭塞范围；
- 路口、升降机、防火门等共享资源；
- 站点容量和工艺互锁；
- 车辆位置反馈方式；
- 故障码和现场处置说明；
- 充电站和电量阈值；
- 生产任务优先级和交期规则；
- 网络、服务器、SQL Server 和备份目录；
- 操作员、审批人和管理员账号；
- 蓝绿发布和回退环境。

## 4. 现场联调顺序

```text
PLC 离线点位校验
→ 单点只读测试
→ 单点受控写入测试
→ 单车空载
→ 单车负载
→ 多车同向
→ 单轨相向
→ 站点拥堵
→ 充电与低电量
→ 车辆故障接管
→ 急停与恢复
→ Host 重启对账
→ 数据库恢复
→ 蓝绿切换与回退
→ 连续生产压力
```

任何步骤失败时，停止进入下一步骤。

## 5. 正式投产门槛

必须同时满足：

- 最新 Windows CI 全部通过；
- `/health/live` 和 `/health/ready` 正常；
- 生产就绪报告无 Critical 和 Error；
- 三方一致性报告有效；
- 最近逻辑备份校验通过；
- 正式场景仿真达到验收门槛；
- 容量基线覆盖预计峰值任务率；
- PLC 点位版本一致；
- 所有车辆位置确认；
- 活动路权和闭塞范围正确；
- 故障和急停演练通过；
- 重启和数据库恢复演练通过；
- 蓝绿切换和回退演练通过；
- 操作员权限和双人审批通过；
- 设备、工艺、生产和信息化负责人签署。

## 6. 禁止事项

正式投产前禁止：

- 根据仿真推荐自动修改生产参数；
- 未复核 PLC 程序版本直接导入点位；
- 从备份自动恢复活动任务和运动命令；
- 两个 WCS 实例同时向同一车辆控制器写命令；
- 物理占用未清除时释放路权；
- 绕过双人审批执行危险写入、冲突处置或命令补偿；
- 将离线验收 Passed 视为现场投产签署。

## 7. 最终软件交付物

- `Wcs.Core` 调度和控制内核；
- `Wcs.Application` 后台闭环；
- `Wcs.Infrastructure` SQL 和文件持久化；
- `Wcs.Host` API、健康检查和指标端点；
- `Wcs.Desktop` 调度、联调、诊断、韧性和验收看板；
- 第一至第十二阶段设计文档；
- 第一至第十二阶段测试方案和 CI 清单；
- 逻辑备份和恢复流程；
- 最终仿真与验收报告导出。

## 8. 研发阶段结束后的工作方式

第十二阶段通过 CI 后，不再继续用“第十三阶段”扩展核心架构。

后续工作以现场项目为单位进行：

```text
现场配置包
现场点位包
现场路线拓扑
现场调度参数
联调缺陷单
验收报告
生产版本发布单
```

核心架构新增能力应重新进入设计评审，而不是直接在现场分支临时修改。
