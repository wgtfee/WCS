# EMS/RGV 配置参数参考手册

## 1. 目的

本文汇总 Wcs.Host 中与 EMS/RGV 调度、PLC、可观测性、韧性、仿真、数据库和部署相关的主要配置项。实际默认值以当前 `appsettings.json` 和代码为准，生产修改必须经过版本和变更管理。

## 2. ConnectionStrings

```json
{
  "ConnectionStrings": {
    "WcsDb": "..."
  }
}
```

| 参数 | 说明 | 生产建议 |
|---|---|---|
| WcsDb | SQL Server 连接字符串 | 使用专用账号，不使用开发密码 |

## 3. Simulator

```json
{
  "Simulator": {
    "Enabled": true,
    "TransportTps": 2
  }
}
```

| 参数 | 说明 | 生产建议 |
|---|---|---|
| Enabled | 是否启用 3 PLC / 9 DB 内置模拟轮询，并禁止注册真实 PLC 连接 | 实车现场必须为 false |
| TransportTps | 模拟运输速率 | 仅开发/演示使用 |

`Enabled=true` 时 Host 会启动 `SimulatorBackgroundService`，模拟信号仍经过结构体解析、StateCenter、EventBus、持久化和 SignalR 链路。该模式不得与真实 PLC 模式同时启用。

## 4. WcsOptions.PlcPolling

```json
{
  "WcsOptions": {
    "PlcPolling": {
      "Enabled": true,
      "IntervalMs": 100
    }
  }
}
```

| 参数 | 说明 | 建议范围 |
|---|---|---|
| Enabled | PLC 轮询总开关 | 现场 true |
| IntervalMs | 基础轮询间隔 | 50～1000ms，按 PLC 负载验证 |

过小会增加 PLC 和网络压力，过大会增加状态和回执延迟。

## 5. WcsOptions.Persistence

| 参数 | 说明 | 建议 |
|---|---|---|
| IntervalSeconds | 通用状态持久化周期 | 根据恢复目标设置，典型 5～30 秒 |

活动命令和关键状态仍应在业务变更时及时持久化，不能只依赖周期快照。

## 6. WcsOptions.Snapshot

| 参数 | 说明 |
|---|---|
| IntervalSeconds | 快照周期 |
| MaxSnapshots | 内存/仓库快照保留数量 |

## 7. TransportObservability

```json
{
  "TransportObservability": {
    "Enabled": true,
    "ConsistencyInspectionIntervalSeconds": 30,
    "HealthEvaluationIntervalSeconds": 10,
    "TraceRetentionCount": 5000,
    "DegradedScoreThreshold": 80,
    "UnhealthyScoreThreshold": 50,
    "RaiseConsistencyAlarms": true,
    "EnablePrometheusEndpoint": true,
    "EnableOtlpExporter": false,
    "OtlpEndpoint": "http://localhost:4317"
  }
}
```

| 参数 | 说明 | 注意事项 |
|---|---|---|
| Enabled | 可观测性总开关 | 关闭不应影响调度 |
| ConsistencyInspectionIntervalSeconds | 三方巡检周期 | 首次自动巡检会延迟 |
| HealthEvaluationIntervalSeconds | 健康评分周期 | 不宜小于 PLC 稳定反馈周期 |
| TraceRetentionCount | 内存 Trace 数量 | 过大会增加内存 |
| DegradedScoreThreshold | 降级阈值 | 应大于 Unhealthy 阈值 |
| UnhealthyScoreThreshold | 不健康阈值 | 根据现场门槛确认 |
| RaiseConsistencyAlarms | 是否产生一致性报警 | 关闭后仍保留报告 |
| EnablePrometheusEndpoint | 是否暴露 `/metrics` | 网络需受控 |
| EnableOtlpExporter | 是否发送 OTLP | 离线 Collector 可启用 |
| OtlpEndpoint | Collector 地址 | 不可配置互联网地址 |

## 8. TransportResilience

```json
{
  "TransportResilience": {
    "Enabled": true,
    "PreflightIntervalSeconds": 60,
    "AutomaticBackupEnabled": true,
    "BackupIntervalMinutes": 60,
    "BackupRetentionCount": 48,
    "MaximumJournalRecords": 5000,
    "MaximumBackupAgeMinutes": 180,
    "RequireReadyBeforeAutomaticBackup": false,
    "BackupDirectory": "data/transport-backups"
  }
}
```

| 参数 | 说明 | 注意事项 |
|---|---|---|
| Enabled | 韧性服务开关 | 关闭会影响生产就绪和自动备份 |
| PreflightIntervalSeconds | 生产就绪检查周期 | 最小应覆盖 PLC/SQL 稳定时间 |
| AutomaticBackupEnabled | 自动逻辑备份 | 建议启用 |
| BackupIntervalMinutes | 备份周期 | 按 RPO 和磁盘容量 |
| BackupRetentionCount | 保留份数 | 默认 48 |
| MaximumJournalRecords | 备份内 Journal 上限 | 防止载荷过大 |
| MaximumBackupAgeMinutes | 备份过期阈值 | 超过后 Readiness Warning |
| RequireReadyBeforeAutomaticBackup | 未就绪时是否禁止备份 | 故障取证场景建议 false |
| BackupDirectory | 文件目录 | 配置 ACL 和磁盘监控 |

## 9. TransportSimulation

具体配置类以代码为准，主要类别包括：

| 参数类别 | 说明 |
|---|---|
| DefaultTravelSeconds | 缺少历史行驶时间时的默认值 |
| DefaultServiceSeconds | 缺少装卸时间时的默认值 |
| ForecastBucketSeconds | 拥堵预测时间桶 |
| MaximumScenarioTasks | 单场景任务上限，生产安全值 5000 |
| MaximumScenarioVehicles | 单场景车辆上限 |
| MaximumScenarioStations | 单场景站点上限 |
| MaximumScenarioFaults | 单场景故障上限 |
| MaximumScenarioHorizonSeconds | 最大仿真窗口，最多 30 天 |
| MaximumForecastComplexity | 任务数×预测桶上限 5,000,000 |
| MaximumHistoricalRecords | 历史 Journal 查询上限 50,000 |
| MaximumCapacityGridPoints | 容量网格上限 200 |
| MaximumCapacityVehicleCount | 单点车辆数上限 200 |
| MaximumTaskRatePerHour | 任务率上限 10,000/h |
| MaximumCapacityTasksPerPoint | 单点任务数上限 5,000 |
| MaximumEstimatedCapacityTasks | 总估算任务数上限 250,000 |
| RetentionCount | 仿真历史保留数量 |

生产环境不要随意提高安全上限。更大规模仿真应使用独立离线工具。

## 10. 生产整定参数

通过 `TransportProductionTuningOptions` 管理，常见参数：

- 任务老化权重；
- 交期紧迫权重；
- 恢复任务权重；
- 站点拥堵惩罚；
- 每周期最大派单数；
- 派单周期；
- 趋势采集周期；
- 趋势保留数量；
- 单轨反向等待老化；
- 最低派单电量。

这些参数应通过 API 和版本管理保存，不建议直接写 appsettings。

## 11. 站点配置

`TransportStationDefinition`：

| 参数 | 说明 |
|---|---|
| StationId | 站点唯一编号 |
| Name | 名称 |
| Capacity | 容量 |
| MaximumQueuedTasks | 最大排队任务数 |
| Enabled | 是否启用 |

运行时占用数量由状态服务维护，不应作为静态配置覆盖。

## 12. 单轨配置

`TransportSingleTrackSectionDefinition`：

- SectionId；
- Name；
- OrderedNodeIds；
- Capacity；
- Enabled；
- 方向切换/等待策略相关参数。

有序节点顺序决定 Forward/Reverse，修改前必须与现场路线复核。

## 13. 驱动端点

`TransportDriverEndpointDefinition` 主要字段：

- DriverId；
- Kind；
- Protocol；
- Endpoint；
- Enabled；
- 连接/超时参数。

生产 Endpoint 和凭据应由安全配置或现场密钥管理提供。

## 14. PLC 点位映射

常见参数：

- Mode；
- HeartbeatTimeoutMs；
- PollIntervalMs；
- HeartbeatTag；
- CurrentNodeTag；
- OperatingStateTag；
- StateSequenceTag；
- CommandSequenceTag；
- CommandCodeTag；
- CommandRequestTag；
- AcknowledgedSequenceTag；
- CommandAcceptedTag；
- CommandCompletedTag。

点位映射通过专用存储和版本控制管理，不应直接长期维护在 appsettings。

## 15. PlcConnections / PlcBlocks

通用 WCS PLC 配置可包含：

- PlcName；
- Address；
- Rack；
- Slot；
- BlockNumber；
- Length；
- PollIntervalMs；
- StructType。

现场地址必须由 PLC 工程师确认。

## 16. S7CommPlus

| 参数 | 说明 |
|---|---|
| Address | PLC 地址 |
| Password | 访问密码，禁止明文提交生产值 |
| TimeoutMs | 通信超时 |

## 17. Desktop

Desktop 配置至少包含 Host ServerUrl。要求：

- 使用 HTTPS 或受控内网；
- 不包含数据库/PLC 连接；
- 不在配置中保存用户明文密码。

## 18. IIS/Host 配置

关注：

- ASPNETCORE_ENVIRONMENT；
- 监听地址和端口；
- stdout 日志；
- 应用池回收；
- 请求大小；
- HTTPS 证书；
- 反向代理超时；
- 服务账号权限。

## 19. 参数变更流程

```text
记录当前值和版本
→ 说明变更原因和预期
→ 离线仿真/测试
→ ChangeConfiguration 申请
→ 独立审批
→ 应用
→ 观察指标
→ 必要时快照回滚
```

## 20. 配置检查清单

- [ ] ConnectionString 使用生产专用账号
- [ ] Simulator.Enabled 正确
- [ ] PLC 地址和点位版本正确
- [ ] 车辆和 Driver 类型一致
- [ ] 站点容量正确
- [ ] 单轨有序节点正确
- [ ] 可观测性周期合理
- [ ] 备份目录可写且受保护
- [ ] 仿真安全上限未放大
- [ ] Desktop ServerUrl 正确
- [ ] 密码和令牌未写入仓库
- [ ] 配置版本和审批记录已保存
