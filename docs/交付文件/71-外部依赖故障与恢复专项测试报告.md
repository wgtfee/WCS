## 5. 首轮异常与修正记录

S5 第一版专项 CI 曾在静态隔离检查失败。原因不是 Runtime 或 Host 功能失败，而是正则使用裸 `SqlCommand`，误匹配了仿真枚举 `SqlCommandTimeout`。

修正方式：

- 删除容易误判的裸 Token；
- 改为检测真实 SQL 连接/Provider 依赖，例如 `SqlConnection`、`Microsoft.Data.SqlClient`、`System.Data.SqlClient`；
- 不降低真实网络/SQL/PLC/调度隔离规则。

修正后 Functional Head 完成全部首轮门禁。
