# EMS/RGV 部署安装与环境配置手册

## 1. 适用范围

本文说明 Wcs.Host、Wcs.Desktop、SQL Server、IIS、备份目录和可观测性组件在离线 Windows 现场的安装、配置、启动和验证流程。

## 2. 推荐环境

| 项目 | 建议 |
|---|---|
| 操作系统 | Windows Server 2019/2022 或经项目验证的 Windows 版本 |
| .NET | .NET 8 Hosting Bundle / Desktop Runtime |
| 数据库 | SQL Server 2019 或以上 |
| Web 宿主 | IIS OutOfProcess 或 Windows Service |
| CPU | 生产最少 4 核，按车辆和任务量评估 |
| 内存 | 最少 8GB，推荐 16GB 以上 |
| 磁盘 | SSD，日志、备份和数据库分区预留空间 |
| 网络 | WCS、PLC、数据库和操作终端使用受控工业网络 |

## 3. 发布物

应包含：

```text
Wcs.Host 发布目录
Wcs.Desktop 发布目录
appsettings 现场模板
数据库初始化/升级脚本
点位表模板
拓扑和站点附件
交付文档
版本清单和 SHA-256
```

不得将开发机连接字符串和真实密码作为默认生产配置交付。

## 4. 数据库准备

1. 创建 WCS 数据库和专用账号；
2. 授予所需表、索引和执行权限；
3. 配置备份策略；
4. 在非生产环境先执行初始化；
5. 启动 Host 由 `DatabaseInitializer` 创建/校验所需结构；
6. 检查所有运输配置、状态、治理、点位和 Journal 表。

生产账号不建议使用 `sa`。

## 5. Host 配置

### 5.1 ConnectionStrings

```json
{
  "ConnectionStrings": {
    "WcsDb": "Server=...;Database=...;User Id=...;Password=...;TrustServerCertificate=True;"
  }
}
```

### 5.2 Simulator

现场实车联调前必须确认：

```json
{
  "Simulator": {
    "Enabled": false
  }
}
```

模拟环境保持 `true`。

`true` 会启动内置 3 PLC / 9 DB 模拟轮询，并阻止真实 PLC 连接注册；`false` 才会注册 S7、标签轮询及按配置启用的 Modbus、OPC UA 连接。切换后必须重启 Host，不能在同一进程中同时运行两种模式。

### 5.3 Observability

配置健康、一致性周期、Trace 保留、Prometheus 和 OTLP。

### 5.4 Resilience

配置生产就绪周期、自动备份、保留数量和备份目录。

### 5.5 Simulation

配置仿真安全上限。生产环境不设置自动压力测试。

## 6. 备份目录

默认：

```text
data/transport-backups
```

要求：

- Host 服务账号具有读写权限；
- 普通操作员无删除权限；
- 目录位于有容量监控的磁盘；
- 定期复制到离线备份介质；
- 防病毒软件不得锁定临时文件写入；
- 不建议与 IIS 临时目录共用。

## 7. IIS 部署

### 7.1 安装组件

- IIS Web Server；
- ASP.NET Core Hosting Bundle；
- URL Rewrite（若使用网关）；
- ARR（若使用反向代理）；
- Windows Authentication 或项目认证组件。

### 7.2 应用池

- .NET CLR：No Managed Code；
- 启动模式：AlwaysRunning；
- Idle Timeout：按项目设置，生产调度不应被空闲回收；
- 专用服务账号；
- 开启 stdout 日志仅用于启动排障，稳定后关闭或限制。

### 7.3 站点

配置：

- 物理目录；
- HTTP/HTTPS 绑定；
- 证书；
- 防火墙；
- 请求大小和超时；
- 健康检查路径。

## 8. Windows Service 部署

若 Host 作为 Windows Service：

1. 使用专用账号；
2. 设置自动启动（延迟启动）；
3. 依赖 SQL Server/网络服务可用；
4. 恢复策略设置为失败后重启，但避免高频循环；
5. 日志写入指定目录或 Windows Event Log；
6. 服务停止前执行 Drain，不直接终止进程。

## 9. Desktop 部署

- 安装 .NET 8 Desktop Runtime；
- 配置 Host ServerUrl；
- 限制只能访问受控 Host；
- 现场终端按角色分配账号；
- Desktop 不直接连接数据库和 PLC；
- 升级 Desktop 不应影响 Host 控制闭环。

## 10. 启动顺序

建议：

```text
网络和 PLC
→ SQL Server
→ WCS Host
→ 检查 /health/live
→ 等待点位和状态恢复
→ 检查 /health/ready
→ Desktop/MES 开始接入
```

Host 内部主要顺序：

```text
数据库初始化
→ 运行配置加载
→ PLC 点位映射加载
→ 状态恢复
→ Driver 轮询和对账
→ 生产配置/队列恢复
→ 可观测性/韧性/仿真历史恢复
→ 周期任务运行
```

## 11. 启动验收

必须检查：

- `/health/live` 返回成功；
- `/health/ready` 首次评估后符合预期；
- 数据库连接正常；
- 车辆配置和点位数量正确；
- PLC 心跳和节点可读；
- 无未确认活动命令；
- 一致性报告无 Critical/Error；
- 自动备份目录可写；
- Prometheus `/metrics` 可访问或明确关闭。

## 12. 网络与防火墙

仅开放必要端口：

- Host HTTP/HTTPS；
- SQL Server；
- PLC 协议端口；
- OTLP/Prometheus（若使用）；
- 运维远程端口按项目安全策略。

PLC 网络不应直接暴露到办公网或互联网。

## 13. 日志目录

日志应：

- 使用滚动文件；
- 限制单文件和保留周期；
- 系统日志与 PLC 通信日志分类；
- 记录 TraceId；
- 禁止记录密码、令牌和完整敏感载荷；
- 配置磁盘空间告警。

## 14. 离线安装包

离线交付应包含：

- .NET Hosting Bundle 安装包；
- .NET Desktop Runtime；
- IIS 组件安装说明；
- 数据库脚本；
- WCS 发布包；
- 配置模板；
- 驱动依赖；
- 校验文件；
- 回退版本发布包。

## 15. 升级前检查

1. 生产队列是否可 Drain；
2. 是否存在活动任务和物理占用；
3. 数据库备份是否完成；
4. 逻辑备份是否完成并校验；
5. 新旧配置和 Schema 是否兼容；
6. 回退包是否可用；
7. 现场负责人是否批准窗口。

## 16. 卸载与回退

卸载前禁止删除数据库和备份目录。回退时优先恢复应用版本；只有确认 Schema 不兼容时才执行数据库恢复。
