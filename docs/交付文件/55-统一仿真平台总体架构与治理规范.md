# 统一仿真平台总体架构与治理规范

## 1. 定位

本文定义 WCS Simulation & Verification v1.0 的 S0 基线。S0 是独立验证线，不属于统一调度“第十三阶段”。它复用现有 `Wcs.Simulator`，只增加版本治理、环境隔离、确定性随机源和 Evidence 契约，不新增控制算法。

## 2. 复用与新增

现有能力继续保留：`ScenarioRunner`、`SimulatorOrchestrator`、`VirtualPlant`、`TransportGenerator`、`ChaosMonkey`、`SignalReplayPlayer`、PLC/设备模拟器。

S0 新增：

```text
Wcs.Simulator/Governance
├── SimulationGovernanceOptions
├── SimulationScenarioManifest
├── SimulationScenarioValidator
├── SimulationScenarioRegistry
├── SimulationBoundaryGuard
├── DeterministicSimulationRandom
└── SimulationEvidenceEnvelope
```

后续 S1～S8 必须复用这些治理契约，不得自行定义场景版本、随机源或 Evidence 格式。

## 3. 环境边界

仿真 API 只有同时满足以下条件才可见：

```text
Simulator.Enabled=true
SimulationGovernance.Enabled=true
Environment ∈ {Simulation, SimulationLoadTest}
Environment != Production
```

其他环境统一返回 404。若 Production 误设 `Simulator.Enabled=true`，`SimulatorBackgroundService` 失败关闭，不启动模拟 PLC。

## 4. 场景 Manifest

必填字段：SchemaVersion、ScenarioId、Version、Seed、ScenarioFile、ContentSha256、CreatedAtUtc、Source、ApprovedBy、ApprovedAtUtc。

约束：

- 当前 SchemaVersion=1；
- ScenarioId/Version 使用受限字符集；
- Seed 非零且显式版本化；
- ScenarioFile 为相对路径，禁止绝对路径、`.`、`..`；
- 内容不能为空，默认最大 1 MB，硬上限 16 MB；
- ContentSha256 必须匹配；
- 审批时间不得早于创建时间。

## 5. 不可变版本

唯一键为 `ScenarioId|Version`。相同内容和 ManifestHash 可幂等注册；修改内容、Seed、文件、来源或审批信息必须发布新 Version。

## 6. 确定性

`DeterministicSimulationRandom` 使用显式 Seed。禁止使用当前时间、未记录 Seed 或各模块自行使用 `Random.Shared`。相同场景版本、Seed 和输入必须得到相同序列。

## 7. Evidence

Evidence 包含 ScenarioId、Version、ManifestHash、Seed、起止时间、按 Sequence 排序的记录和 EvidenceHash。

- Sequence 唯一；
- 记录数量有界；
- 输入顺序变化不影响规范化 Hash；
- Evidence 仅证明软件仿真行为，不替代 HIL 和现场验收。

## 8. API

```text
GET  /api/simulation/governance/status
GET  /api/simulation/governance/scenarios
POST /api/simulation/governance/scenarios/validate
```

S0 POST 仅做内存校验和不可变版本登记，不执行场景、不写生产 SQL、不写 PLC、不修改任务、路权和调度。

## 9. 安全边界

- 无 PLC 写入、设备停止、任务取消；
- 无路线、区段、路权、车辆选择或派单修改；
- Simulation 默认关闭异常、ML、可插拔模型和 Forecast；
- 仓库不保存真实点位、拓扑、场景、凭据和现场数据；
- S10 页面只能调用治理 API，不能绕过治理层。

## 10. 回退

```text
SimulationGovernance__Enabled=false
Simulator__Enabled=false
```

回退不影响生产 PLC、调度、异常、健康、维修和 Forecast 数据。

## 11. 后续顺序

```text
S0 治理
→ S1 场景引擎与虚拟时钟
→ S2 虚拟 PLC
→ S3 虚拟 RGV/区段
→ S4 调度/交通/死锁
→ S5 MES/SQL/网络故障
→ S6 异常/健康/RUL 合成数据
→ S7 全系统集成恢复
→ S8 容量长稳/HIL 准备
→ S9 真实 HIL/试运行
→ S10 统一页面
```
