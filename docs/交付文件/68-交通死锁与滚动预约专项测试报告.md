## 5. 首轮发现与修复

首轮开发测试发现并修复：

1. 两个含列表的 record 使用默认引用相等，导致状态恢复/Controller 快照测试误失败；改为比较规范化 JSON 内容；
2. 容量测试把等待请求误当作新预约；改为真实触发 `MaximumWaitingRequests`；
3. 工作流中的 `dotnet test | tee` 未启用 `pipefail`，可能掩盖测试失败；两条 S4 专项均已启用 `set -euo pipefail` 并校验预期测试数量；
4. 静态组合检查使用错误字面量；改为验证实际 `VirtualTrafficOptions` 组合类型；
5. 冲突域 Capacity 增加 1～16 的硬边界，防止阻塞车辆状态无界增长。

上述修复没有删除测试、降低容量、使用 `continue-on-error` 或放宽安全门槛。
