## 6. 文档变更规则

1. 代码、配置、数据库、API、阈值、模型、数据集版本、验证指标、Manifest 或控制边界变化必须同步文档。
2. 现场点位、拓扑、资产编号、维修规则、MES 地址、密钥、真实模型、许可证和未脱敏数据形成项目附件，不写入通用文档。
3. 同一根因图 Version 不得对应不同 GraphHash；同一规则集 Version 不得对应不同 RuleSetHash；同一模型 Version 不得对应不同 ManifestHash、ArtifactSha256 或 FeatureSchema。
4. 已签署验收记录不得覆盖，应新增版本。
5. LoadTest、MlLoadTest、ForecastLoadTest 接口不得在生产开放。
6. 治理、复核、反馈、标签审批、模型激活和 Outcome API 必须接入项目身份权限并保存 Actor 与原因。
7. 将健康评分、根因、维修建议、故障概率或 RUL 接入自动控制前，必须建立独立安全阶段、风险分析和现场验收。
