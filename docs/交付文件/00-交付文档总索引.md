## 8. 文档与治理规则

1. 代码、配置、数据库、API、阈值、模型、特征、数据集、场景、策略或控制边界变化必须同步文档。
2. 真实点位、拓扑、资产、维修规则、MES 地址、SQL ConnectionString、密钥、模型、许可证和未脱敏数据不写入通用仓库。
3. 相同 Version 不得对应不同 Hash、FeatureSchema、Dataset、Seed、Policy 或审批元数据。
4. 已签署验收、Evidence 和 Audit Journal 不得覆盖，只能追加版本或 Journal。
5. Production 默认 fail-closed；IndustrialIntelligence 未经明确批准最高 L0。
6. P0～P5 软件自动化等级不得超过 L1；P6 可评估 L2/L3 软件准备度，但不授予生产控制权。
7. L4 安全关键控制永久禁止 AI 直接执行。
8. AI/SQL/Model/Feature/Decision/Optimization/Maintenance Learning/Readiness 故障不得阻塞 PLC Polling、TaskScheduler、TaskOrchestrator、DeviceManager 和交通控制。
9. P4 Maintenance Learning 只允许维修学习/治理元数据变更；`ControlWriteAllowed=false`、`AutoTrainingAllowed=false`、`AutoModelActivationAllowed=false`。
10. P5 Digital Twin Optimizer 只允许软件仿真实验、Candidate 排名和 Evidence；`ControlWriteAllowed=false`、`AutoProductionPolicyReplacementAllowed=false`、`ProductionAutomationAllowed=false`。
11. P6 Bounded Automation Readiness 默认 Disabled；`ProductionEnablementAllowed=false`，Host/Desktop GET-only，SQL Evidence append-only，最终声明只能是 `software-side ready only`。
12. P6 永久禁止 EmergencyStop、SafetyReset、SafetyDoor/LightCurtain/MechanicalInterlock bypass、PlcForceWrite、AutomaticRoadRight/Block release、UnapprovedShutdown、StateMachineBypass、TrafficConstraintBypass；未知 operation 数值同样 fail-closed。
13. `Wcs.IndustrialIntelligence`、`Wcs.ModelOps`、`Wcs.FeatureCenter`、`Wcs.DecisionIntelligence`、`Wcs.MaintenanceLearning`、`Wcs.Optimization` 不得依赖 PLC、CommandBus、TaskScheduler、TaskOrchestrator、DeviceManager、Dispatch、Traffic 或 RouteReservation mutation path。
14. 所有队列、窗口、模型、查询、批次、缓存、Outbox 和保留期必须有界。
15. Full Regression 必须校验 exact Head、固定 child 数量、所有 child `completed/success`、`allSuccess=true` 和 PR Head 未漂移。
16. Simulation、Mock、手写 JSON、hosted CI 和虚拟 8h/24h 不得描述为真实 HIL 或现场安全验收。
17. 模型必须先 Validate、Candidate、Shadow，再进入 Champion/Challenger；必须保留 Fallback/Quarantine/Rollback，并禁止自动晋级。
18. Dataset 必须 Point-in-Time 正确并保存 DatasetHash、FeatureSchemaHash 和标签版本。
19. Decision Proposal 必须记录 FeatureSnapshot、ModelVersion、硬约束结果和 Evidence。
20. Maintenance TrainingLabel 默认 Pending，只有显式批准后才可进入 Dataset；Causal/Counterfactual 结果必须标记为估计 Evidence。
21. Optimization Hard Constraint 不是可加权软目标；任一 Run 失败必须使整个 Candidate 失去有效排名资格。
22. 自动化等级提升必须有独立风险分析、KillSwitch、Rate/Budget Limit、CircuitBreaker、回滚和真实现场验收；P6 软件 readiness 本身不是 Production authorization。
