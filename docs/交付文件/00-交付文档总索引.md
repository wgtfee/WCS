## 2. 交付说明

本目录是 EMS/RGV 统一调度的正式交付文档包。原有 `docs/架构文件`、`docs/设计流程文件` 和 `docs/测试文件` 保留为架构基线、阶段研发记录和自动化测试依据；本目录将十二阶段内容横向整合为可供实施、运维、审计和现场验收使用的正式说明书。

本交付包不代表现场已经完成实车投产。软件研发完成、CI 通过、现场联调完成和正式投产签署是四个独立状态。

## 6. 文档变更规则

1. 文档版本必须与发布版本或提交 SHA 关联。
2. 控制逻辑、状态机、数据库结构、API 或 PLC 点位规则变化时必须同步更新对应文档。
3. 现场项目特定点位、拓扑、站点编号和车辆参数不得直接写入通用文档，应形成项目实例附件。
4. 文档修改需通过代码评审和 CI，不允许仅在线下修改后不回写仓库。
5. 已签署的现场验收记录不得覆盖，应新增版本并保留历史。
