# EMS/RGV 调度策略与交通控制说明书

## 1. 目的

本文说明生产任务竞争、车辆选择、路径规划、站点拥堵、闭塞、单轨会车、路口冲突、死锁处理和故障接管策略。

## 2. 调度分层

```text
生产任务层：决定哪个任务先进入派单
统一派单层：决定使用哪台车辆和哪条路径
交通准入层：判断当前路径是否允许进入
路权层：原子预留连续路段和离散交通资源
执行层：根据反馈滚动释放和扩展路权
```

各层不得相互越权：生产优先级不直接释放路权；交通控制不直接修改生产订单优先级；Driver 不负责选择车辆。

## 3. 任务竞争策略

### 3.1 有效优先级

```text
EffectivePriority = BasePriority
                  + ProductionOrderPriority
                  + AgingScore
                  + DeadlineScore
                  + RecoveryScore
                  - StationCongestionPenalty
```

### 3.2 等待老化

等待时间越长，任务分数逐步增加，避免低优先级任务永久饥饿。老化只在真实派单周期刷新，查询页面和仿真场景生成使用纯快照。

### 3.3 交期紧迫

当当前时间接近 Deadline 时增加优先级。超过交期的任务继续保留，但必须在趋势和仿真指标中计入违约。

### 3.4 恢复任务

经人工确认可恢复的任务可以增加恢复权重，但不允许绕过车辆状态、站点容量、物理占用或 PLC 在线检查。

## 4. 车辆选择

### 4.1 候选条件

- 在线；
- Idle；
- 车辆类型允许；
- 能力匹配；
- 可信节点存在；
- 电量不低于派单阈值；
- 未处于维护、故障或充电锁定状态。

### 4.2 基础排序

优先考虑空驶距离短、活动任务少和电量高的车辆。最终占用通过 Registry CAS 完成，排序本身不产生状态变化。

### 4.3 并发竞争

两个请求同时选择同一车辆时，只有一个请求能成功执行 `Idle → Executing`。失败请求必须释放已经获得的逻辑预留并尝试下一候选。

## 5. 路径策略

统一拓扑由节点和有向边组成。边可包含：

- 距离/权重；
- 允许车辆能力；
- 所属闭塞区段；
- 交通资源编号；
- 是否故障/禁用；
- 是否占用。

路径计算支持最短、故障绕行和拥堵权重。现场为单路线时也必须建模节点与区段，不能只保存一个字符串路线号。

## 6. 滚动路权

### 6.1 初始窗口

派单时只预留足够安全的初始窗口，不要求一次锁定整条长路径，以提高并行度。

### 6.2 位置反馈

车辆确认经过节点后：

1. 释放已经通过且物理占用清除的资源；
2. 向前申请新的滚动窗口；
3. 新窗口申请失败时暂停继续前进；
4. 不允许先释放后申请导致安全空窗。

## 7. 闭塞区段

闭塞区段是物理安全单元。规则：

- 同一时刻只允许满足区段策略的车辆进入；
- 进入前必须获得逻辑许可；
- 实际进入后标记物理占用；
- 离开确认后才能清除物理占用；
- PLC 无连续位置时，以到站、读码、RFID、编码器或控制器回执作为确认依据。

## 8. 路口冲突

路口中的多个通行方向映射为冲突资源。冲突矩阵由项目拓扑附件定义。

示例：

| 通行方向 | 与 A→B | 与 C→D | 与 A→C |
|---|---:|---:|---:|
| A→B | 否 | 是 | 是 |
| C→D | 是 | 否 | 是 |
| A→C | 是 | 是 | 否 |

冲突资源预留应与路径窗口在同一次准入过程中完成。

## 9. 单轨会车

### 9.1 方向判断

单轨定义包含有序节点。顺序方向为 Forward，反向为 Reverse。

### 9.2 许可规则

- 当前无车辆时允许任一方向获得许可；
- 已有方向许可时，相同方向可在容量内编队；
- 相反方向必须等待；
- 反向等待达到老化阈值后，在当前方向清空时优先切换；
- 物理占用未清除时不得切换方向。

### 9.3 延迟释放

任务已完成但 PLC 物理占用仍存在时，许可继续保留。后台清理器仅在执行终态且占用清除后释放。

## 10. 站点拥堵

站点定义：

- Capacity；
- CurrentOccupancy；
- MaximumQueuedTasks；
- Enabled。

当目标站点满载或排队超过上限，任务进入 `WaitingForStation`，不占用车辆和路权。

## 11. 死锁检测

### 11.1 等待图

任务等待其他任务持有的资源时记录有向边。检测到环表示资源等待死锁。

### 11.2 受害者选择

优先选择：

- 优先级低；
- 完成进度低；
- 未装载；
- 无已确认物理占用；
- 可安全回退到已定义节点。

### 11.3 禁止自动解除条件

- 已装载；
- 正在装卸；
- OccupancyConfirmed；
- 无安全回退点；
- PLC 状态不可信。

上述情况只报警并进入人工恢复。

## 12. 故障车辆接管

顺序：

```text
识别车辆故障
→ 检查原任务阶段
→ 检查物理占用
→ 检查货物状态
→ 选择替代车辆
→ 创建接替任务
```

取货前、无物理占用时可自动接管。已装载或占用未清除时返回人工恢复状态。

## 13. 充电策略

- 低于最低派单电量的车辆不参与新任务；
- 空闲车辆可进入充电评估；
- 充电站按容量预留；
- 充电任务优先级不得高于安全停车和故障恢复；
- 生产高峰可通过配置调整充电阈值，但必须经过版本和审批流程。

## 14. 仿真策略

生产策略变更前应使用离线仿真比较：

- BaselineDynamicPriority；
- AgingFirst；
- DeadlineFirst；
- CongestionAware；
- BalancedBatch。

仿真推荐不自动写入生产配置。

## 15. 项目配置附件

每个现场应单独提供：

1. 拓扑节点表；
2. 路段和方向表；
3. 闭塞区段表；
4. 路口冲突矩阵；
5. 单轨有序节点表；
6. 安全回退点表；
7. 站点容量表；
8. 车辆能力表；
9. 充电站表；
10. 调度参数确认单。
