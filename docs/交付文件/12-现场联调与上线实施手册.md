# EMS/RGV 现场联调与上线实施手册

## 1. 目的

本文规定从现场资料收集、点位导入、单点联调、空载/带载测试、生产切换到上线观察期的实施步骤。

## 2. 联调前资料

必须具备：

- PLC 程序版本和备份；
- 车辆清单；
- 车辆类型和能力；
- 点位表；
- 命令码、状态码、故障码；
- 拓扑节点和边；
- 闭塞区段；
- 路口冲突矩阵；
- 单轨有序节点；
- 站点容量；
- 充电站；
- 安全回退点；
- MES/WMS 任务字段；
- 网络和账号信息。

资料缺失时不得通过猜测 PLC 地址或现场位置继续实施。

## 3. 环境确认

1. Host、Desktop、SQL 和 PLC 网络连通；
2. 时间同步；
3. 数据库备份；
4. 发布版本和 Commit 确认；
5. Simulator 模式确认；
6. 服务账号和目录权限；
7. 急停和安全回路由设备方验证；
8. 现场有设备、PLC、生产和信息化人员。

## 4. 配置导入顺序

```text
运行配置
→ 车辆和 Driver
→ 拓扑与交通资源
→ 站点与单轨
→ PLC 点位映射
→ 故障码字典
→ 生产整定参数
```

每一步保存后记录版本和创建人。

## 5. 点位导入与校验

1. 使用模板整理 XLSX；
2. 导入联调工作台；
3. 检查重复 VehicleId；
4. 检查 Driver 引用；
5. 检查必填标签；
6. 检查数据类型和读写方向；
7. 校验通过后申请配置变更；
8. 独立审批后应用；
9. 保存导入文件、校验报告和版本。

## 6. 单点读取

依次验证：

- Heartbeat；
- CurrentNode；
- OperatingState；
- StateSequence；
- Battery；
- FaultCode；
- Occupancy；
- 当前命令和确认序号。

读取结果必须与 PLC 监控值一致。

## 7. 受控单点写

仅在设备安全、车辆停稳、无生产任务和审批完成时执行。

优先测试无运动风险信号；运动相关请求必须由 PLC/设备人员现场确认。

记录：

- OperationId；
- 信号；
- 旧值；
- 新值；
- PLC 实际结果；
- 执行人；
- 审批人；
- 时间；
- 恢复值。

## 8. 命令握手测试

覆盖：

1. 正常接收；
2. 正常完成；
3. PLC 拒绝；
4. 确认序号不匹配；
5. 完成超时；
6. 心跳冻结；
7. 网络断开；
8. WCS 重启后已有确认；
9. 相同命令序号重复发送；
10. Stop 补偿。

## 9. 车辆状态联调

验证：

- Offline/Idle；
- Idle/Executing；
- Faulted；
- Maintenance；
- Charging；
- 位置节点变化；
- 乱序状态序号拒绝；
- 断线后不推算位置。

## 10. 路径和交通测试

### 10.1 单车

- 每条路线；
- 每个站点；
- 每个闭塞；
- 每个路口；
- 每个单轨方向；
- 每个回退点。

### 10.2 多车

- 同向追车；
- 相向会车；
- 路口冲突；
- 单轨方向切换；
- 站点满载；
- 路权等待；
- 死锁构造和安全处置。

### 10.3 物理占用

确认车辆实际进入区段后，软件超时和任务取消不能释放该区段。

## 11. 任务生命周期测试

```text
创建
→ 派单
→ 取货移动
→ 到达取货点
→ 装载确认
→ 载货移动
→ 到达目标点
→ 卸载确认
→ 完成
```

覆盖暂停、恢复、取消、故障和人工恢复。

## 12. MES/WMS 联调

验证：

- RequestId 唯一；
- 重复请求幂等；
- 网络超时重试；
- 状态查询；
- 取消；
- 错误码；
- 503 Readiness；
- TraceId 关联；
- 任务字段映射。

## 13. 故障演练

现场必须演练：

- 车辆故障；
- PLC 断线；
- 心跳冻结；
- WCS Host 重启；
- 数据库短时不可用；
- 路权残留；
- 单轨车辆未清场；
- 装载后故障；
- 命令超时；
- 急停和解除急停。

演练前后保存运行快照、一致性报告和审计记录。

## 14. 性能和容量

使用第十二阶段离线仿真形成目标任务率和车辆数基线。现场再进行受控压力验证，不能直接在生产高峰试探极限。

检查：

- 吞吐；
- P95 等待；
- PLC 响应；
- 队列峰值；
- 站点拥堵；
- 车队利用率；
- CPU、内存、磁盘和数据库负载。

## 15. 上线前 Gate

必须全部满足：

- CI 通过；
- Readiness 无 Error/Critical；
- PLC 点位签署；
- 拓扑和闭塞签署；
- 空载/带载测试通过；
- 故障演练通过；
- 数据库和逻辑备份完成；
- 回退包可用；
- 权限和审批验证；
- MES 幂等验证；
- 生产窗口批准。

## 16. 切换流程

```text
停止创建新任务
→ Drain 已有任务
→ 确认车辆停稳和占用清除
→ 创建数据库/逻辑备份
→ 部署新版本
→ 启动并等待 Readiness
→ 单车冒烟
→ 少量生产任务
→ 扩大流量
→ 进入观察期
```

## 17. 回退条件

- Readiness 持续 Unhealthy；
- PLC 命令相关性异常；
- 车辆位置或路权出现不可解释差异；
- 关键任务无法完成；
- 队列或响应超过约定门槛；
- 数据库升级不兼容；
- 现场安全负责人要求回退。

## 18. 回退流程

```text
停止新任务
→ 保持设备安全停机
→ 保存证据和快照
→ 回退应用版本
→ 必要时恢复数据库
→ 加载旧配置/点位
→ 三方对账
→ 冒烟测试
→ 恢复生产
```

## 19. 上线观察期

建议至少覆盖一个完整生产周期。每日检查：

- 任务完成率；
- P95 等待；
- 命令失败；
- 车辆故障；
- 一致性差异；
- 备份；
- 人工干预；
- MES 重复请求；
- 现场反馈。
