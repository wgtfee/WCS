## 2. Simulation 配置

```json
{
  "Simulator": {
    "Enabled": true,
    "TransportTps": 2
  },
  "SimulationGovernance": {
    "Enabled": true,
    "ScenarioDirectory": "data/simulation-scenarios",
    "MaximumScenarioBytes": 1048576,
    "MaximumEvidenceRecords": 10000,
    "AllowedEnvironments": [
      "Simulation",
      "SimulationLoadTest"
    ]
  }
}
```

SimulationLoadTest 使用相同治理边界，可提高模拟吞吐和 Evidence 上限，但仍禁止真实控制写入。

## 3. Production

Production 保持：

```json
{
  "Simulator": {
    "Enabled": false
  }
}
```

`SimulationGovernanceOptions.Enabled` 代码默认值为 false。即使外部配置误开启 Simulator 和 Governance，Production 仍被 BoundaryGuard 与 SimulatorBackgroundService 双重拒绝。

## 4. 参数

| 参数 | 默认 | 约束 |
|---|---:|---|
| Governance.Enabled | false | 必须显式开启 |
| ScenarioDirectory | data/simulation-scenarios | 禁止真实数据 |
| MaximumScenarioBytes | 1 MB | 1 byte～16 MB |
| MaximumEvidenceRecords | 10,000 | 1～1,000,000 |
| AllowedEnvironments | Simulation、SimulationLoadTest | 禁止 Production |
| Simulator.Enabled | false | 与 Governance 双开关 |

## 7. S0 控制隔离

禁止：PLC Write、Device Stop、Task Cancel、Route Change、Reservation Release、Vehicle Selection、Dispatch。

S0 POST 只在进程内 Registry 保存版本 Hash，不执行场景、不持久化生产 SQL。持久化场景仓库属于 S1 后续范围。
