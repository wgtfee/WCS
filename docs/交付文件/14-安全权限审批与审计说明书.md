# EMS/RGV 安全、权限、审批与审计说明书

## 1. 目标

本文定义统一调度系统的身份、权限、危险操作审批、目标绑定、一次性执行、审计和数据保护规则。

## 2. 安全原则

1. 最小权限；
2. 读写分离；
3. 高风险操作双人复核；
4. 审批目标不可替换；
5. 审批不可重复使用；
6. 所有危险操作可追踪；
7. 物理安全高于业务连续性；
8. Desktop 不绕过 Host 治理；
9. 生产数据库和 PLC 不向普通用户直接开放。

## 3. 角色建议

| 角色 | 主要权限 |
|---|---|
| Viewer | 查询车辆、任务、报警、指标和报告 |
| Operator | 创建/取消业务任务、确认操作流程 |
| Dispatcher | 生产队列和调度操作 |
| DeviceEngineer | 驱动诊断、点位校验、联调申请 |
| ConfigAdministrator | 配置变更申请 |
| Approver | 审批指定危险操作 |
| Auditor | 查询审批和审计，不执行操作 |
| SystemAdministrator | 部署、账号和系统配置，不默认拥有现场运动权限 |

不建议使用一个“超级管理员”账号完成申请、审批和执行全过程。

## 5. 危险操作

至少包括：

- PLC 单点写；
- 命令补偿；
- 恢复冲突处置；
- 生产配置变更；
- 配置快照回滚；
- 站点/单轨定义修改；
- 真实驱动点位应用；
- 故障任务人工接管；
- 备份恢复准备后的正式应用。

## 6. 审批模型

治理记录包含：

- OperationId；
- OperationType；
- TargetId；
- Reason；
- Requester；
- RequestedAtUtc；
- Approver；
- ApprovedAtUtc；
- Status；
- ExecutionResult。

## 7. 审批流程

```text
申请人创建操作申请
→ 系统检查申请权限
→ 审批人查看目标和原因
→ 审批人批准或拒绝
→ 执行人调用目标操作
→ 系统校验 OperationId/Type/Target
→ BeginExecution 原子成功
→ 执行
→ 完成或失败审计
```

## 8. 独立审批

系统必须拒绝：

- 申请人审批自己的请求；
- 无审批权限人员审批；
- 已拒绝操作继续执行；
- 已执行 OperationId 再次执行；
- 用配置审批执行 PLC 写；
- 用 A 车辆审批写 B 车辆；
- 用一个 SnapshotId 审批回滚到另一个快照。

## 9. 目标绑定

TargetId 示例：

| 操作 | TargetId |
|---|---|
| PLC 单点写 | `VehicleId:SignalName` |
| 恢复冲突 | ConflictId |
| 命令补偿 | CommandId |
| 配置回滚 | SnapshotId |
| 点位应用 | VehicleId 或 MapId |
| 单轨修改 | SectionId |
| 站点修改 | StationId |

执行接口必须重新计算目标并与审批记录比较。

## 10. 一次性执行

`BeginExecution` 必须原子地把状态从 Approved 改为 Executing。并发调用只能有一个成功。

执行失败后：

- 记录失败原因；
- 不允许修改 TargetId 后重试；
- 是否允许同目标重新申请由业务规则决定；
- 必须创建新的 OperationId。

## 11. 审计记录

每条审计至少包含：

- AuditId；
- OperationId；
- UserId；
- Action；
- Target；
- Before/After 摘要；
- Result；
- TraceId；
- IP/客户端信息（若系统提供）；
- OccurredAtUtc。

## 12. 认证要求

- 生产环境必须启用认证；
- 默认匿名只允许必要的 live 探针，ready 和业务 API 是否匿名由项目安全策略决定；
- 报告导出、备份下载、手动备份和恢复准备必须认证；
- 服务间调用建议使用证书、Windows 身份或受控令牌；
- 令牌不得写入日志。

## 13. 网络安全

- PLC 网络隔离；
- Host 仅开放必要端口；
- 使用 HTTPS；
- IIS/网关限制来源；
- 联调接口仅在受控网络开放；
- 数据库不对普通终端开放；
- 远程运维需经过堡垒机或项目批准方式。

## 14. 数据安全

- 配置文件不提交生产密码；
- 备份目录设置 ACL；
- 审计记录禁止普通用户删除；
- 点位表和拓扑属于项目敏感资料；
- 导出报告避免包含密码和完整令牌；
- 日志中的 PLC 载荷按必要范围记录。

## 15. 安全事件

发生以下情况应立即升级：

- 未授权 PLC 写入；
- 重复运动命令；
- 双实例同时写同一车辆；
- 审批目标不匹配；
- 审计记录缺失；
- 备份被篡改；
- 生产配置未经审批变化；
- 用户绕过 Host 直接修改数据库；
- 凭据泄漏。

## 16. 定期审计

每月至少检查：

- 活跃账号和角色；
- 高风险权限；
- 申请人与审批人关系；
- 失败/拒绝操作；
- 配置变更；
- PLC 写入；
- 恢复冲突；
- 命令补偿；
- 备份下载；
- 异常登录和来源地址。
