# Wcs.Desktop AtomUI 产品化第一批页面改造说明

## 1. 目标

本次改造将 Wcs.Desktop 已经安装并初始化的 AtomUI 6.0.5 从“运行时已接入、页面少量使用”推进到“产品页面真实使用”。本次只改 Desktop UI，不修改 WCS、EMS/RGV、PLC、Traffic、Dispatch、IDI 的业务与控制逻辑。

## 2. 现状修正

改造前项目已经具备：

- `AtomUI.Desktop.Controls 6.0.5`；
- `AtomUI.Desktop.Controls.DataGrid 6.0.5`；
- `Program.BuildAvaloniaApp().WithAtomUIDefaultOptions()`；
- `App.Initialize().UseAtomUI(...)`；
- `UseDesktopControls()`；
- `UseDesktopDataGrid()`。

但大量 XAML 仍直接使用 Avalonia 原生 `Button / TextBox / DataGrid / TabControl`，视觉语言并未真正统一。

## 3. 第一批迁移页面

### 3.1 智能运维中心

`/AssetIntelligence`

迁移到：

- AtomUI `Card`；
- AtomUI `Statistic`；
- AtomUI `Button`；
- AtomUI `TabControl / TabItem`；
- AtomUI `DataGrid / DataGridTextColumn`。

保留 Health、Root Cause、Maintenance、Failure Forecast/RUL 原有 ViewModel 与 API 契约。

### 3.2 IDI 总览

`/IndustrialIntelligenceOverview`

迁移到：

- AtomUI KPI Card + Statistic；
- AtomUI Primary Button；
- AtomUI DataGrid；
- AtomUI Card 形式的治理说明。

### 3.3 IDI-P2 Feature Center

`/FeatureCenter`

迁移到：

- AtomUI Card / Statistic；
- AtomUI Button；
- AtomUI `LineEdit`；
- AtomUI DataGrid。

Schema、Snapshot、Point-in-Time Dataset 查询行为不变。

### 3.4 IDI-P3 Shadow Decision Center

`/ShadowDecision`

迁移到：

- AtomUI Card / Statistic；
- AtomUI Button；
- AtomUI `LineEdit`；
- AtomUI DataGrid；
- Proposal 单选交互保持原 ViewModel 绑定。

Approve / Reject 仍然只改变 Proposal 治理状态，Outcome 仍然只记录结果证据，不新增生产控制写链路。

## 4. 统一页面样式

新增：

`src/Wcs.Desktop/Styles/AtomUIProductStyles.axaml`

统一：

- 页面标题；
- 页面副标题；
- Section 标题；
- Toolbar 状态文本；
- Safety / Boundary 信息条。

业务页面不再各自重复定义一套字体、间距和边界样式。

## 5. FluentTheme 兼容策略

当前 `FluentTheme` 暂时保留。

原因：MainWindow 和尚未迁移页面仍存在 Avalonia 原生控件，如果立即移除 FluentTheme，旧页面可能失去默认模板或产生视觉回归。

迁移策略：

1. 第一批：智能运维、IDI 总览、P2、P3；
2. 第二批：EMS/RGV、Traffic、Dispatch、Observability、Recovery；
3. 第三批：Alarm、Device、Task、Event Log、配置与现场工作台；
4. 最后迁移 MainWindow Shell / Navigation，再评估移除 FluentTheme。

## 6. CI 门禁

新增 `WCS Desktop AtomUI Productization` workflow：

- Release 编译 `Wcs.Desktop`；
- 验证 AtomUI Runtime 注册；
- 验证 4 个第一批页面存在 AtomUI namespace；
- 验证 Card / Button / DataGrid 等 AtomUI 控件真实使用；
- 静态禁止 4 个页面重新出现原生 `Button / TextBox / DataGrid / TabControl`；
- 生成 exact-head UI evidence Artifact。

## 7. 安全边界

本次改造只涉及 Desktop 表现层：

- 不修改 PLC 写入；
- 不修改 CommandBus；
- 不修改 TaskScheduler / TaskOrchestrator；
- 不修改 EMS/RGV Dispatch；
- 不修改 Traffic / RouteReservation；
- 不提升 IDI 自动化权限；
- P3、P5、P6 原有 zero-control / recommendation-only / software-side-ready 边界保持不变。
