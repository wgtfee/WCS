# 交通冲突与区段预约仿真设计说明

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 阶段 | WCS Simulation & Verification v1.0 S4 |
| 配置节 | `SimulationVirtualTraffic` |
| 运行环境 | `Simulation`、`SimulationLoadTest` |
| 状态基础 | S1 `SimulationStateStore`、Checkpoint、Replay、State Hash |
| 运动基础 | S3 虚拟 RGV、显式路线、区段位置与虚拟时间 |

## 2. 设计目标

S4 用于在不连接真实 PLC、RGV 或调度执行链的条件下，确定性验证：

- 同一区段、对向区段、合流口和交叉口冲突；
- 冲突域容量与车辆预约；
- 虚拟时间租约、到期与排队再授权；
- 滚动预约与已通过区段释放；
- 等待图和循环等待；
- 两车及多车死锁检测；
- 确定性受害者选择；
- 仿真会话内的死锁处置；
- Checkpoint、Replay 与 Evidence 一致性。

S4 不负责真实车辆制动、现场路权释放、任务取消、路线改写或生产派单。

## 3. 核心模型

### 3.1 冲突域

一个 `VirtualTrafficZoneDefinition` 将一个或多个 S3 区段映射为同一物理冲突域：

- `SharedSegment`：共享闭塞区；
- `OpposingDirection`：对向轨道或双向共用区；
- `Merge`：合流口；
- `Intersection`：交叉口；
- `Custom`：项目定义冲突域。

每个 S3 区段最多属于一个冲突域。单冲突域最多 16 个区段，避免状态值和等待图无界增长。

### 3.2 预约

预约包含：

- ReservationId；
- ZoneId、SegmentId、VehicleId；
- Priority；
- Granted/Released/Expired；
- GrantedAt、ExpiresAt；
- Version。

预约租约只依据 S1 虚拟时间，不使用 `Task.Delay` 或真实墙钟等待。

### 3.3 等待请求和等待图

当冲突域容量已满时，系统创建有界等待请求，并记录全部当前阻塞车辆：

```text
WaitingVehicle -> BlockingVehicle
```

等待边按车辆、冲突域和请求排序，保证同一输入得到相同图。

### 3.4 死锁

S4 对等待图执行 Tarjan 强连通分量检测。包含两个及以上车辆的强连通分量，或单车辆自环，构成死锁。

受害者选择规则固定为：

```text
数值 Priority 最大
→ 请求 Sequence 最新
→ VehicleId 字典序最大
```

数值越大表示越适合被牺牲。规则必须在项目适配真实业务前单独评审；当前只用于确定性仓库验证。

### 3.5 仿真内处置

处置步骤：

1. 释放受害者在当前会话中的活动预约；
2. 取消受害者的等待请求；
3. 按 Priority、Sequence、VehicleId 顺序重新评估其他等待请求；
4. 标记死锁为 Resolved；
5. 写入环形审计。

处置不会调用生产 `UnifiedTransportDispatchEngine`、`TransportTrafficCoordinator`、`IRouteReservationManager`、任务引擎、设备驱动或 PLC Writer。

## 4. 滚动预约

`traffic.rolling.reserve` 从 S3 车辆当前 `RouteIndex` 起，按路线顺序申请有限个前视区段。遇到第一个冲突即停止继续申请。

`traffic.rolling.release` 根据 S3 已通过路线段释放对应预约，不修改车辆路线和位置。

## 5. StateStore 结构

所有状态均写入 S1 会话状态：

```text
__vtraffic.zone.*
__vtraffic.segmentZone.*
__vtraffic.reservation.*
__vtraffic.request.*
__vtraffic.deadlock.*
__vtraffic.index.*
__vtraffic.audit.*
```

索引按固定数量分块；审计使用有界环形槽位。因此预约、等待图和死锁自动进入 Checkpoint、Replay 和 FinalStateHash。

## 6. 配置参数

| 参数 | Simulation | SimulationLoadTest | 说明 |
|---|---:|---:|---|
| `MaximumZones` | 256 | 2,000 | 冲突域上限 |
| `MaximumSegmentsPerZone` | 16 | 16 | 单冲突域区段上限 |
| `MaximumReservations` | 2,048 | 10,000 | 预约记录上限 |
| `MaximumWaitingRequests` | 2,048 | 10,000 | 等待请求上限 |
| `MaximumDeadlocks` | 512 | 5,000 | 死锁记录上限 |
| `MaximumAuditRecords` | 5,000 | 20,000 | 环形审计容量 |
| `MaximumRollingLookAheadSegments` | 16 | 64 | 滚动预约前视上限 |
| `DefaultReservationLeaseMilliseconds` | 60,000 | 60,000 | 默认虚拟租约 |
| `MaximumReservationLeaseMilliseconds` | 86,400,000 | 604,800,000 | 最大虚拟租约 |

## 7. Host 边界

Host 只提供只读检查：

```text
GET /api/simulation/virtual-traffic/runs/{runId}/status
GET /api/simulation/virtual-traffic/runs/{runId}/zones
GET /api/simulation/virtual-traffic/runs/{runId}/zones/{zoneId}
GET /api/simulation/virtual-traffic/runs/{runId}/reservations
GET /api/simulation/virtual-traffic/runs/{runId}/waiting
GET /api/simulation/virtual-traffic/runs/{runId}/wait-graph
GET /api/simulation/virtual-traffic/runs/{runId}/deadlocks
GET /api/simulation/virtual-traffic/runs/{runId}/deadlocks/{deadlockId}
GET /api/simulation/virtual-traffic/runs/{runId}/audit
```

不存在 Host 直接预约、直接释放或直接处置死锁 API，避免绕过场景 DSL 与 Replay。

## 8. 安全结论

- Production 和非批准环境返回 404；
- 代码默认仿真关闭；
- 不包含真实拓扑、车辆、点位、凭据或现场数据；
- 无真实 PLC/车辆写入；
- 无生产任务取消、路线修改、车辆选择或派单；
- 仓库 Evidence 不替代 HIL、制动距离、机械互锁、真实协议或现场验收。
