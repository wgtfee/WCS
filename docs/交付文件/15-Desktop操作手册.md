# Wcs.Desktop EMS/RGV 操作手册

## 1. 目的

本文说明 Wcs.Desktop 中 EMS/RGV 相关页面的用途、主要字段、允许操作和安全限制。

## 2. 登录与连接

启动 Desktop 后应确认：

- ServerUrl 指向正确 Host；
- 连接状态为 Connected；
- 当前用户身份和角色正确；
- Host `/health/ready` 符合预期；
- 页面时间与现场时间一致。

Desktop 不直接连接 PLC 或数据库。

## 3. EMS/RGV 调度

菜单：

```text
EMS / RGV 调度
```

查看：

- 车辆编号和类型；
- 在线、状态和可信节点；
- 电量；
- 活动任务；
- 执行阶段；
- 路权；
- 任务结果。

操作时应先确认车辆和物理现场状态。该页面不用于任意 PLC 点位写入。

## 4. 交通控制与死锁

菜单：

```text
交通控制与死锁
```

查看：

- 交通资源定义；
- 当前持有者；
- 等待关系；
- 物理占用；
- 死锁周期；
- 处置建议。

如果资源显示 `OccupancyConfirmed`，不得要求通过软件强制释放。

## 5. 充电与运行优化

菜单：

```text
充电与运行优化
```

查看：

- 充电站容量；
- 充电队列；
- 低电量车辆；
- 充电计划；
- 任务重分配；
- 性能快照。

优化评估只提供当前建议，实际参数变更需走配置治理。

## 6. 生产级调度

菜单：

```text
生产级调度
```

页签：

- 任务竞争队列；
- 动态优先级；
- 站点拥堵；
- 单轨许可；
- 调度试算；
- 决策回放；
- 故障接管；
- 趋势。

队列页面使用纯快照，不会因为刷新改变任务优先级。

### 6.1 调度试算

试算不会：

- 标记车辆；
- 预留路权；
- 创建执行；
- 写 PLC。

### 6.2 故障接管

如显示等待物理清场，必须由现场确认车辆、货物和区段，不能直接强制接替。

## 7. 配置与审计

菜单：

```text
配置与审计
```

查看：

- 运行配置版本；
- 治理操作；
- 审批状态；
- 审计记录；
- Journal。

危险操作必须使用正确 OperationId。界面显示批准不代表可以改变目标后继续执行。

## 8. PLC 驱动诊断

菜单：

```text
PLC 驱动诊断
```

查看：

- Driver 连接；
- 设备在线；
- 最近读取时间；
- 心跳；
- 当前节点；
- 命令和确认序号；
- 点位映射版本。

立即轮询只读取状态，不应频繁连续点击影响 PLC 通信。

## 9. 现场联调工作台

菜单：

```text
现场联调工作台
```

能力：

- 点位表导入；
- 模板查看；
- 校验；
- 单点读取；
- 受控单点写；
- 在线探测；
- 通信 Trace；
- 故障码；
- 恢复冲突；
- 命令补偿。

### 9.1 单点写

必须先取得审批，确认车辆停稳且无生产任务。写入后验证 PLC 实际值并恢复测试信号。

### 9.2 命令补偿

Stop 可能允许受控补偿；Move、Load、Unload 默认显示人工处理，不应强制重试。

## 10. 可观测性与一致性

菜单：

```text
可观测性与一致性
```

页签：

- 健康组件；
- 一致性差异；
- 链路追踪；
- 指标；
- 配置快照。

允许：刷新、立即健康评估、立即只读巡检。

不允许：自动修正车辆、路权或 PLC 状态。

## 11. 生产韧性与恢复演练

菜单：

```text
生产韧性与恢复演练
```

查看：

- 生产就绪检查；
- 运行基线；
- 逻辑备份；
- 备份完整性；
- 隔离演练。

Desktop 不提供配置恢复按钮。备份校验通过只表示可准备配置快照，不表示可以自动恢复任务。

## 12. 调度仿真与最终验收

菜单：

```text
调度仿真与最终验收
```

查看：

- 仿真运行；
- 策略 A/B；
- 优化推荐；
- 容量基线；
- 拥堵预测；
- 最终验收报告。

仿真结果不自动应用生产参数。

## 13. 报警页面

处理步骤：

1. 查看报警码、级别和发生时间；
2. 结合车辆、任务、PLC 和 Trace 查看原因；
3. 确认物理现场；
4. Acknowledge；
5. 执行安全处置；
6. 条件消失后确认恢复；
7. 检查任务/车辆是否仍需人工恢复。

## 14. 刷新和数据时间

- 页面刷新显示的是查询时快照；
- 时间字段可能是 UTC，界面按本地转换；
- 车辆状态变化快时应结合更新时间；
- 不能以页面未及时刷新替代 PLC 现场确认。

## 15. 常见提示

| 提示 | 含义 |
|---|---|
| Conflict | 当前状态、版本或资源不允许操作 |
| Unauthorized | 未登录或身份无效 |
| Forbidden | 权限或审批不满足 |
| NotReady | Host 尚未完成恢复或存在阻断项 |
| WaitingForTraffic | 正在等待路权/单轨 |
| WaitingForStation | 目标站点满载 |
| WaitingForVehicle | 无可用车辆 |

## 16. 使用禁令

1. 不使用共享管理员账号进行申请和审批。
2. 不在未知物理状态下执行恢复操作。
3. 不通过连续刷新或重复点击制造重复业务请求。
4. 不把仿真推荐当作生产命令。
5. 不在联调工作台测试未确认的 PLC 地址。
6. 不在生产过程中导入未经审核的新点位表。
