# WCS 智能中心产品化页面补齐说明

## 1. 目标

本次工作不新增新的 IDI 阶段，而是在 IDI-P0～P6 软件主线完成后，将已经存在但缺少产品入口的能力补齐到 Wcs.Desktop，并修复 IDI-P3 交付历史中“文档声明 Host/Desktop/SQL、实际缺少正式 Host Controller / SQL Store / Desktop 页面”的落地缺口。

基线：P6 已完成并 Squash 合入 `develop@a5b540b0159794035fd565f3a0563b13faf72cc4`。

## 2. 新增页面

### 2.1 智能运维中心 `/AssetIntelligence`

统一汇总已有 AnomalyEngine v3.4～v3.9 的产品视图：

- Asset Health Score / Grade / Fusion Risk；
- Root Cause Analysis；
- Maintenance Recommendation；
- Failure Probability / RUL Forecast。

页面只读，不新增 PLC 写入、设备停机、任务取消、路线、路权或 Dispatch 修改动作。

### 2.2 IDI 总览 `/IndustrialIntelligenceOverview`

统一探测 P0～P6 的 Host 状态，展示：

- Stage 可用性；
- Environment；
- Maximum Automation Level；
- ControlWriteAllowed；
- fail-closed / unavailable 状态。

总览仅聚合状态，不提升任何阶段的自动化权限。

### 2.3 IDI-P2 Feature Center `/FeatureCenter`

补齐 P2 Desktop 产品入口：

- Feature Definition 列表；
- Feature Schema 查询；
- Feature Snapshot 查询；
- Point-in-Time Dataset Manifest 查询。

页面只读，用于模型、决策、Dataset 和 Lineage 的追踪与复现。

### 2.4 IDI-P3 Shadow Decision Center `/ShadowDecision`

补齐 P3 正式产品入口及实际缺失的基础设施：

- `SqlDecisionProposalStore`；
- `DecisionIntelligencePersistenceFactory`；
- `/api/industrial-intelligence/proposals` Host API；
- Proposal 列表与详情；
- Constraint / Explanation / Evidence；
- Approval / Reject 治理动作；
- Approval Audit；
- Outcome 回填。

Approve / Reject 仅改变 Proposal 治理状态；Outcome 仅写真实结果证据。P3 仍保持：

- `MaximumAutomationLevel <= L1`；
- `ControlWriteAllowed=false`；
- `ProductionAutomationAllowed=false`；
- 不引用 CommandBus、PLC Writer、TaskScheduler、TaskOrchestrator、DeviceManager、Dispatch、Traffic 或 RouteReservation 写链路。

## 3. Desktop 菜单

产品入口补齐后，默认菜单增加：

- 智能运维中心；
- IDI 总览；
- IDI-P2 Feature Center；
- IDI-P3 Shadow Decision Center。

原有 P1 ModelOps、P4 Maintenance Learning、P5 Digital Twin Optimizer、P6 Bounded Automation Readiness 保留。

新增 `.github/workflows/intelligence-productization.yml`，至少验证：

1. Host Release Build；

## 5. 不在本次范围

- 不建立 IDI-P7；
- 不启用 P6 Production Automation；
- 不把 P3 Proposal 自动转换为控制命令；
- 不替代真实 S9 HIL / Site / Mechanical Safety / Production Authorization；
- 不修改已完成 EMS/RGV 调度和 Traffic 的安全控制事实源。
