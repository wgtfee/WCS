# 外部依赖故障仿真设计说明

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 阶段 | Simulation & Verification S5 |
| 范围 | MES、SQL Server、HTTP、Network 与 Custom 外部依赖的确定性故障仿真 |
| 功能基线 | `af96cd925b101a44ccb70ce6bd65b4dfd21ac527` |
| 安全属性 | Simulation-only；不建立真实 MES、SQL、Socket、PLC、RGV 或生产调度连接 |

S5 的目标不是复制真实 MES、SQL Server 或网络栈，而是在统一场景 DSL、虚拟时钟、Checkpoint、Replay 与 State Hash 框架内，确定性地重现外部依赖异常，验证 WCS 在超时、拒绝、连接异常、重试、熔断、幂等和恢复场景中的行为。

## 3. 外部系统模型

`VirtualExternalSystemKind` 支持：

- `Mes`
- `SqlServer`
- `Http`
- `Network`
- `Custom`

每个 Endpoint 只保存仿真标识、类型、熔断状态、连续失败次数、Open 截止虚拟时间和版本号，不包含真实 URL、连接字符串、账号、Token 或证书。

## 4. 故障模型

`VirtualExternalFaultKind` 支持：

| 故障 | 用途 |
|---|---|
| `Timeout` | 请求超过仿真超时 |
| `Unavailable` | 外部服务不可用 |
| `HttpStatus` | 指定 HTTP 状态失败 |
| `InvalidResponse` | 响应结构/语义无效 |
| `DuplicateResponse` | 模拟重复响应 |
| `SqlDeadlock` | 模拟 SQL 死锁错误 |
| `SqlCommandTimeout` | 模拟 SQL 命令超时 |
| `ConnectionReset` | 模拟连接重置 |
| `HighLatency` | 增加确定性虚拟延迟 |
| `PacketLoss` | 模拟网络丢包失败 |
| `HalfOpen` | 模拟半开连接失败 |

Fault 使用 `StartsAtOffsetMilliseconds` 与 `EndsAtOffsetMilliseconds` 定义虚拟时间窗，可显式 Clear。运行时不调用墙钟，不 `Task.Delay`，不启动后台网络线程。

## 5. 请求、重试与结果

请求输入包含：Endpoint、Operation、IdempotencyKey、PayloadHash、MaxAttempts、TimeoutMilliseconds 和 RetryDelayMilliseconds。

结果状态：

- `Succeeded`
- `Failed`
- `TimedOut`
- `RejectedByCircuit`

每次 Attempt 保存虚拟偏移、状态、持续时间、HTTP 状态、错误码、重复响应标记和命中的 FaultId。重试延迟只通过虚拟时间计算，不通过真实睡眠等待。

`MaximumRetryAttempts` 对重试次数实施硬上限；请求、Fault、Endpoint 和 Audit 都有容量上限，避免恶意或错误场景无限增长。

## 6. 熔断器

Endpoint 熔断状态：

```text
Closed -> Open -> HalfOpen -> Closed/Open
```

连续失败达到 `CircuitFailureThreshold` 后进入 Open，并记录 `CircuitOpenUntilOffsetMilliseconds`。到达虚拟恢复时间后允许 HalfOpen 探测；成功关闭熔断并清零连续失败，失败重新 Open。

整个状态机由虚拟时间和确定性请求序列驱动，Replay 后必须得到相同状态和 State Hash。

## 7. 幂等模型

成功请求通过 `IdempotencyKey` 建立仿真幂等记录。同一 Endpoint/业务键再次调用时可返回已成功结果，并将 `IdempotencyReplayed=true`，不得创建第二条业务 Request 记录。

S5 的幂等验证只是 WCS 行为仿真证据，不代表真实 MES 或真实数据库已经实现相同幂等协议；现场集成仍需按实际接口契约验收。

## 9. Host 只读检查

路由：

```text
/api/simulation/virtual-external/runs/{runId}/status
/api/simulation/virtual-external/runs/{runId}/endpoints
/api/simulation/virtual-external/runs/{runId}/endpoints/{endpointId}
/api/simulation/virtual-external/runs/{runId}/faults
/api/simulation/virtual-external/runs/{runId}/faults/{faultId}
/api/simulation/virtual-external/runs/{runId}/requests
/api/simulation/virtual-external/runs/{runId}/requests/{requestId}
/api/simulation/virtual-external/runs/{runId}/audit
```

控制器从活动 Run 创建 Checkpoint，再从 canonical state 构造只读 `VirtualExternalRuntime`。Production、未批准环境或未知 Run 返回 404；Audit `take` 有边界校验。

## 10. 安全隔离

S5 明确禁止：

- `HttpClient` 或真实 HTTP/MES 调用；
- `SqlConnection`、真实 SQL Provider 或真实命令执行；
- `Socket`、`TcpClient`、`UdpClient`；
- PLC Client/Writer、真实 RGV 驱动；
- `CommandBus`、`TaskScheduler`、`TaskOrchestrator`、`DeviceManager`；
- `UnifiedTransportDispatchEngine`、`TransportTrafficCoordinator`、`IRouteReservationManager`；
- `DateTime.Now/UtcNow`、`Task.Delay`、`Thread.Sleep`、`Random.Shared` 参与确定性运行时。

S5 证据不能替代真实 MES 联调、SQL 高可用/死锁测试、网络设备测试、HIL、机械安全、制动、PLC 联锁或现场 SAT。

## 11. 验收门禁

S5 使用三层门禁：

1. `WCS Simulation External Failures`：编译 Simulator/Host、10 项专项测试、隔离与配置边界；
2. `WCS Simulation External Determinism`：7 项 Runtime 确定性测试、Checkpoint/Replay、静态隔离；
3. `WCS Simulation S5 Full Regression`：37-child exact-head 累计回归。

功能 Head 首轮已通过 37/37；最终文档 Evidence Head 必须再次通过完全相同的门禁后才允许合并。
