# EMS/RGV 运维监控与故障处理手册

## 1. 目标

本文供生产运维、值班人员和设备工程师使用，说明日常监控、健康判定、告警处置、Trace 查询、三方巡检和常见故障处理。

## 2. 日常监控入口

### 2.1 健康检查

```text
/health/live
/health/ready
/health
```

- live：进程是否存活；
- ready：是否具备接收生产流量条件；
- health：综合检查结果。

### 2.2 指标

```text
/metrics
/api/transport/observability/metrics
```

### 2.3 Desktop

重点页面：

- EMS/RGV 调度；
- 交通控制与死锁；
- 生产级调度；
- PLC 驱动诊断；
- 可观测性与一致性；
- 生产韧性与恢复演练。

## 3. 核心指标

| 指标 | 含义 | 关注条件 |
|---|---|---|
| QueueLength | 等待任务数 | 持续增长 |
| WaitingForVehicle | 无可用车辆 | 车辆故障/能力/电量 |
| WaitingForTraffic | 路权或单轨等待 | 拥堵、死锁、占用未清 |
| WaitingForStation | 站点拥堵 | 下游停机或容量不足 |
| PLCResponseMs | PLC 响应时间 | 突增或超时 |
| OperationFailures | 失败操作数量 | 连续增长 |
| ConsistencyIssues | 三方差异数量 | Error/Critical |
| FleetUtilization | 车队利用率 | 长期过高或过低 |
| P95QueueWait | P95 等待时间 | 超过项目门槛 |
| BackupAge | 最近备份年龄 | 超过配置阈值 |

## 4. 健康评分

组件：

- Consistency；
- Fleet；
- PLC；
- Queue；
- Alarm。

状态：

```text
Healthy
Degraded
Unhealthy
```

健康评分是运维判断依据，不替代设备安全回路。

## 5. 报警处置原则

### 5.1 先确认物理状态

处理交通、位置、故障车辆和命令超时时，先确认车辆是否停稳、货物状态和占用区段。

### 5.2 报警恢复不等于任务恢复

`Recovered` 只表示报警条件消失。车辆 Faulted、任务 Suspended、路权占用和命令失败仍需单独处理。

### 5.3 禁止直接改数据库

不得通过修改 SQL 状态强制车辆 Idle、删除路权或完成命令。必须使用受控恢复接口并保留审计。

## 6. Trace 排障

使用业务 RequestId 或 HTTP `X-Trace-Id` 查询：

```text
入队
→ 派单
→ 车辆选择
→ 路权预留
→ 执行启动
→ PLC 命令
→ PLC 确认
```

检查：

- 哪个阶段耗时；
- 是否产生子 Span；
- VehicleId 是否一致；
- RequestId 是否贯穿；
- 是否存在失败标签和错误消息。

## 7. 三方一致性巡检

比较：

- SQL；
- 运行时；
- PLC。

常见差异：

| 差异 | 可能原因 | 处置 |
|---|---|---|
| VehiclePositionMismatch | PLC 到位未同步、重启中断 | 读取现场状态并人工确认 |
| PlcDeviceOffline | 网络/PLC/驱动异常 | 检查连接、心跳和防火墙 |
| PlcCommandMismatch | WCS/PLC 命令序号不同 | 禁止重发，执行命令对账 |
| RuntimeExecutionMissing | 恢复顺序或状态丢失 | 检查 SQL 快照和 Journal |
| PersistedReservationMissing | 持久化失败 | 保留运行路权并补充记录 |
| RuntimeReservationMissing | 恢复未加载 | 检查物理占用，禁止自动释放 |

## 8. 常见故障

### 8.1 无车辆可派

检查：

1. 车辆是否在线；
2. 是否 Idle；
3. 电量是否低于阈值；
4. 能力和车辆类型是否匹配；
5. 当前节点是否有效；
6. 是否处于维护或故障；
7. Driver 诊断是否新鲜。

### 8.2 一直等待交通

检查：

- 活动路权；
- 单轨方向；
- OccupancyConfirmed；
- 等待图和死锁；
- PLC 占用信号；
- 前车是否已完成但许可未清理。

禁止直接删除路权。

### 8.3 命令已发送但无确认

检查：

- CommandRequest；
- CommandSequence；
- AckSequence；
- Accepted/Completed；
- 心跳；
- PLC 是否拒绝；
- 点位数据类型；
- 通信 Trace。

运动命令不得盲目重试。

### 8.4 车辆位置不更新

检查到站、读码、RFID、编码器或控制器回执。不得以预计时间手工改成目标节点。

### 8.5 站点满载

检查下游设备、站点占用数量、排队上限和是否存在未释放业务占用。恢复后任务会在下一派单周期重新竞争。

### 8.6 自动备份失败

检查：

- 目录权限；
- 磁盘空间；
- 文件锁；
- 路径配置；
- 服务账号；
- 防病毒软件。

备份失败不影响调度，但应尽快恢复。

### 8.7 Readiness 一直不可用

检查最近生产就绪报告中的 Critical/Error：

- 状态存储不可读；
- 真实 PLC 驱动离线；
- 一致性 Critical；
- 配置重复；
- 点位映射缺失；
- 未完成命令。

## 9. 故障等级建议

| 等级 | 示例 | 处置 |
|---|---|---|
| Information | 一次普通策略等待 | 观察 |
| Warning | 备份过期、队列升高 | 计划处理 |
| Error | 驱动离线、命令超时 | 停止相关车辆新任务 |
| Critical | 物理占用冲突、状态存储不可用 | 停止新任务并人工处置 |

## 10. 值班巡检清单

### 每班

- Readiness；
- 活动报警；
- 离线/故障车辆；
- 等待队列；
- 单轨和路权；
- 最近备份；
- 磁盘空间。

### 每日

- 一致性报告；
- PLC 响应趋势；
- 命令失败和超时；
- P95 等待；
- 车队利用率；
- 数据库备份结果。

### 每周

- 恢复冲突和未关闭故障；
- 审批和审计记录；
- 配置快照；
- 日志保留；
- 备份抽样校验；
- 容量趋势。

## 11. 故障升级

升级信息必须包含：

- 发生时间；
- RequestId；
- TraceId；
- VehicleId；
- 任务阶段；
- 当前节点；
- PLC 命令/确认序号；
- 活动路权；
- 物理状态照片或现场确认；
- 日志和通信 Trace；
- 已执行操作。

## 12. 严禁操作

1. 绕过审批写 PLC。
2. 直接删除活动任务或路权数据库记录。
3. 修改 PLC/WCS 命令序号以伪造完成。
4. 断线时按时间推算车辆位置。
5. 在物理占用未清除时切换单轨方向。
6. 未备份直接修改生产配置。
7. 在生产 Host 运行超安全门槛的大规模仿真。
