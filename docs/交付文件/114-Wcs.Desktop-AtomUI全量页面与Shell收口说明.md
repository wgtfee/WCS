# Wcs.Desktop AtomUI 全量页面与 Shell 收口说明

## 1. 收口目标

本阶段在前六批 AtomUI 页面迁移的基础上完成 Desktop 表现层收口：常用 EMS/RGV、Traffic、Production Dispatch、Observability、Recovery/Resilience、Device、Task、Alarm、Event Log、配置/现场联调以及其余业务页面均已进入 AtomUI 产品化门禁；最后一批处理登录、MainWindow Shell/Navigation 与常用弹层/对话框。

本次仍然只修改 Desktop 表现层和 UI CI，不修改 PLC、CommandBus、TaskScheduler、TaskOrchestrator、Dispatch、Traffic、RouteReservation 或 IDI 自动化权限语义。

## 2. 已迁移的路由业务页面

AtomUI 门禁固定覆盖 28 个业务页面：

- Asset Intelligence / IDI Overview / Feature Center / Shadow Decision；
- EMS/RGV Scheduling / Traffic / Production Dispatch / Observability / Resilience；
- Optimization / PLC Driver Diagnostics / Commissioning / Administration；
- Device / Task / Alarm / Event Log；
- Dashboard / Object Tracking / Tracking Log / Audit Log / System Log；
- Transport Simulation / Simulation Verification；
- ModelOps / Maintenance Learning / Digital Twin Optimizer / Bounded Automation Readiness。

这些页面优先使用 AtomUI `Card`、`Statistic`、`Button`、`LineEdit`、`TabControl`、`DataGrid` 等产品控件，Avalonia 保留为布局与兼容基础。

## 3. 最后一批 Shell 与辅助页面

本批补齐：

- `LoginView`：表单输入改为 AtomUI `LineEdit`，表单容器改为 `Card`，操作按钮改为 AtomUI `Button`；
- `ChangePasswordPage`：改为 AtomUI `Card + LineEdit + Button`；
- `MainWindow`：侧栏导航改为 AtomUI `TreeView`，折叠与状态栏操作改为 AtomUI `Button`，折叠菜单弹层使用 AtomUI `Card + TreeView`；
- `ConfirmDialog`：改为 AtomUI `Card + Button`；
- `ProfileMenuView`：菜单操作改为 AtomUI `Button`；
- `UserProfileOverlay`：内容容器改为 AtomUI `Card`，关闭操作使用 AtomUI `Button`；
- `ChangePasswordOverlay`：输入与操作改为 AtomUI `LineEdit + Button`；
- `NotificationCenterView`：三列消息区改为 AtomUI `Card + ListView`；
- `ClosableTabControl`：自定义 Tab 生命周期保持不变，仅关闭操作替换为 AtomUI `Button`。

## 4. 为什么仍保留 FluentTheme

全量产品化不等于移除 Avalonia 基础设施。当前部分布局或暂未由 AtomUI 替代的基础控件仍可能使用 Avalonia 模板，例如 `Grid`、`StackPanel`、`ScrollViewer`、`Popup/Flyout`、`DatePicker`、部分 `ComboBox`、`ContextMenu` 等。

因此 `FluentTheme` 继续作为兼容兜底，但业务页面的主要交互/数据展示控件由 AtomUI 接管。后续只有在确认所有剩余 Avalonia 控件都具备稳定 AtomUI 替代且不会造成模板回归时，才评估移除 FluentTheme。

## 5. 最终 CI 门禁

`WCS Desktop AtomUI Productization` 升级为 v2 证据：

- Release 编译 `Wcs.Desktop`；
- 验证 AtomUI Runtime 注册；
- 固定核对 28 个路由页面；
- 核对 Login、ChangePasswordPage、MainWindow 及 6 个主要 Shell/辅助控件；
- 检查 `Card / Statistic / LineEdit / Button / TabControl / DataGrid / TreeView / ListView` 产品控件覆盖；
- 静态检查本迁移 PR 不得修改 Core / Infrastructure / Host / Application 控制与业务项目；
- 输出 exact-head Artifact，绑定当前 Head SHA。

## 6. 安全边界

本阶段只改变视觉组件、布局和 UI 门禁：

- 不新增或改变 PLC 写入；
- 不新增或改变 CommandBus 命令；
- 不改变 TaskScheduler / TaskOrchestrator；
- 不改变 Dispatch / Traffic / RouteReservation 控制事实源；
- 不改变报警、任务取消等既有命令语义；
- 不提升 IDI L0-L4 自动化权限；
- 不把 P3/P5/P6 从治理/推荐/软件就绪边界升级为生产自动控制。
