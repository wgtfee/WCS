# EMS/RGV 高可用、备份恢复与容灾手册

## 1. 目标

本文定义单活部署、主备切换约束、状态恢复、逻辑备份、配置回滚、数据库恢复和灾难演练要求。

## 2. 当前安全基线

当前生产基线是单调度实例。即使部署两台服务器，也必须保证同一时刻只有一个实例拥有 PLC 写权限。

在以下能力未全部验证前，禁止双实例同时下发命令：

- 主节点选举；
- 租约续约；
- Fence Token；
- 同一车辆单写通道；
- 活动状态共享；
- PLC 命令幂等；
- 回执去重；
- 接管前对账。

## 3. Active/Standby 设计

### 3.1 Active

- 执行生产派单；
- 写 PLC；
- 更新活动状态；
- 采集健康和备份；
- 持有主节点租约。

### 3.2 Standby

- 不写 PLC；
- 可读取数据库和健康状态；
- 监控 Active 租约；
- 准备接管但不得提前恢复任务；
- 可执行只读诊断。

### 3.3 接管条件

接管必须满足：

1. Active 租约明确过期；
2. 获得新的 Fence Token；
3. Standby 已加载最新持久化状态；
4. 读取 PLC 当前状态；
5. 完成数据库/内存/PLC 三方对账；
6. 活动命令进入确认或人工恢复；
7. Readiness 满足项目门槛。

## 4. 脑裂保护

- PLC 写入必须携带或间接受 Fence Token 约束；
- 旧 Active 恢复网络后必须先降级为 Standby；
- 无法确认主节点时两边都停止新任务，不允许“优先可用性”覆盖物理安全；
- 主节点租约数据库与 PLC 单写权限应独立校验。

## 5. 运行状态恢复

恢复对象：

- 车辆；
- 执行任务；
- 路权；
- 命令；
- 生产队列；
- 配置和点位；
- 单轨许可；
- 充电和重分配记录。

恢复后不得立即续跑，必须读取 PLC 状态并生成一致性报告。

## 6. 逻辑备份

逻辑备份包含：

- 运行配置；
- 生产整定；
- 站点和单轨定义；
- PLC 点位映射；
- 车辆、任务、路权和命令快照；
- 最近 Journal；
- 运行基线。

文件使用 SHA-256 校验、不可覆盖 BackupId 和原子写入。

## 7. 自动备份策略

默认每 60 分钟创建一份，保留 48 份。项目应根据任务量和磁盘容量调整。

自动备份失败：

- 记录 Warning；
- 不停止调度；
- Readiness 可根据备份过期时间进入 Warning；
- 连续失败应升级为运维报警。

## 8. 配置快照和回滚

### 8.1 快照内容

- 运行配置；
- 生产整定；
- 站点定义；
- 单轨定义。

### 8.2 回滚流程

```text
选择目标快照
→ 申请 ChangeConfiguration
→ 独立审批
→ 校验当前版本
→ 创建回滚前安全快照
→ 应用目标配置
→ 记录结果
```

PLC 点位映射不随普通配置快照自动回滚，必须与 PLC 程序版本单独复核。

## 9. 备份恢复准备

从逻辑备份恢复时：

1. 校验文件存在；
2. 校验 SHA-256；
3. 校验 SchemaVersion；
4. 校验标识符和驱动引用；
5. 识别活动任务和命令；
6. 仅导入配置快照；
7. 返回人工恢复清单；
8. 通过治理审批执行配置回滚。

不得自动恢复活动任务、车辆位置、路权和运动命令。

## 10. 数据库备份

逻辑备份不能替代 SQL Server 原生备份。生产应同时执行：

- 全量备份；
- 差异备份；
- 事务日志备份（按恢复目标）；
- 定期恢复验证。

数据库恢复目标需在项目中明确：

- RPO：允许丢失的数据时间；
- RTO：允许恢复所需时间。

## 11. 灾难恢复场景

### 11.1 Host 进程崩溃

- 重启 Host；
- 检查数据库连接；
- 等待恢复和 PLC 首轮读取；
- 检查 `/health/ready`；
- 处理恢复冲突。

### 11.2 WCS 服务器损坏

- 启用备用服务器；
- 恢复发布包和配置；
- 恢复数据库连接；
- 验证备份目录；
- 执行三方对账；
- 人工批准恢复生产。

### 11.3 数据库损坏

- 停止新任务；
- 保持设备安全停机；
- 恢复 SQL 备份；
- 校验 Schema；
- 启动 Host；
- 对账 PLC；
- 活动任务全部人工确认。

### 11.4 PLC 程序更换

- 停止调度；
- 备份旧点位表；
- 确认新 PLC 程序版本；
- 重新导入和校验点位；
- 单点联调；
- 不恢复旧活动命令。

## 12. 恢复演练

隔离演练支持：

- DriverOffline；
- HeartbeatTimeout；
- StateStoreUnavailable；
- OrphanReservation；
- ConfigurationVersionConflict；
- StaleConsistencyReport；
- ActiveCommandAfterRestart。

隔离演练不替代现场实车演练。

| 场景 | 预期结果 | 实际结果 | 证据 | 签字 |

| Host 重启 | 不重复下发命令 | | | |
| 数据库断开 | Readiness 异常，停止新任务 | | | |

## 14. 禁止事项

1. 未确认 Active 已失效即启动 Standby 写 PLC。
2. 从备份直接恢复运动命令。
3. 删除物理占用以“解决”恢复冲突。
4. 未校验数据库备份可恢复就视为备份有效。
5. 只恢复应用文件但忽略配置、点位和数据库版本。
