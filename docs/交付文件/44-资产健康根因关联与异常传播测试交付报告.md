## 3. SQL 对象

### 3.1 Wcs_AssetHealthRootCauseGraphVersion

- Version 唯一；
- GraphHash 唯一；
- 同版本不同 Hash 拒绝；
- 来源、审批和 GraphJson 可审计。

### 3.2 Wcs_AssetHealthRootCauseAnalysis

- AnalysisId 唯一；
- 相同图和事件版本重复分析只写一条；
- Candidates 和 PropagationPaths 保存在不可变 AnalysisJson；
- 人工复核不会覆盖 AnalysisJson。

### 3.3 Wcs_AssetHealthRootCauseReviewJournal

- ReviewId 唯一；
- 多次复核全部保留；
- Actor、Decision、节点、Note 和时间可追溯。

## 10. 人工复核验收

- Confirmed 只能选择推断候选；
- Rejected 不选择节点；
- Supplemented 必须选择已审批图节点并填写说明；
- Review 不修改 GraphVersion 或 GraphHash；
- Review 不删除原始 Candidates 和 Paths；
- Review 不触发 PLC、停机或调度操作；
- 生产 Actor 应来自认证身份。

## 11. 安全边界

已经确认：

- `AssetHealthRootCause.Enabled=false` 为默认；
- Production 默认关闭且 Nodes/Edges 为空；
- 默认 `AllowCycles=false`；
- 无 PLC 写接口、设备停止、任务取消、路线、路权或派单修改；
- 无自动图更新；
- 无生成式 AI 拓扑推断；
- Confidence 不是故障概率或安全等级；
- SQL 故障不阻塞控制链路。
