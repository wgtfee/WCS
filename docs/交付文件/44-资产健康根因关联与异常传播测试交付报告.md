# 资产健康根因关联与异常传播测试交付报告

## 1. 交付范围

本报告记录 AnomalyEngine v3.6 根因关联与异常传播能力的代码、配置、SQL、API、自动化测试和安全边界。

当前交付包括：

- 已审批依赖图模型；
- 图容量、唯一性、引用、边权和环路校验；
- 活动健康事件时间窗口关联；
- 上游候选搜索；
- 最短传播路径；
- Coverage、Topology、Temporal、Severity 可解释评分；
- RootCause / Intermediate / Symptom 角色；
- 确定性 GraphHash 和 AnalysisId；
- SQL 图版本、不可变分析快照和人工复核 Journal；
- Confirmed、Rejected、Supplemented；
- Host 重启恢复；
- 只读 API 和 LoadTest API；
- 默认关闭和控制链路隔离。

## 3. SQL 对象

### 3.1 Wcs_AssetHealthRootCauseGraphVersion

验证：

- Version 唯一；
- GraphHash 唯一；
- 同版本不同 Hash 拒绝；
- 来源和审批信息持久化；
- GraphJson 可审计。

### 3.2 Wcs_AssetHealthRootCauseAnalysis

验证：

- AnalysisId 唯一；
- 相同图和事件版本重复分析只写一条；
- 完整 Candidates 和 PropagationPaths 保存到 AnalysisJson；
- 人工复核不覆盖 AnalysisJson。

### 3.3 Wcs_AssetHealthRootCauseReviewJournal

验证：

- ReviewId 唯一；
- 多次复核全部保留；
- Actor、Decision、SelectedRootCauseNodeId、Note、OccurredAtUtc 可追溯。

## 4. Core 单元测试

`AssetHealthRootCauseAnalysisEngineTests` 覆盖：

1. 上游原因早于下游症状时优先排名；
2. 三节点路径正确标记 RootCause、Intermediate、Symptom；
3. 相同图与事件版本生成相同 AnalysisId；
4. 时间窗口排除过期事件；
5. MaximumPropagationDepth 限制传播范围；
6. `AllowCycles=false` 时拒绝环路；
7. 无图映射事件不生成伪分析。

不得通过删除环路测试、降低覆盖断言或跳过路径验证来使 CI 通过。

## 5. 专项 SQL E2E

工作流：

```text
.github/workflows/anomaly-root-cause.yml
```

场景图：

```text
MOTOR-01 --Controls--> CV-01 --Feeds--> ST-01
```

场景事件：

```text
电机 Degraded
→ 10 秒后输送机 Degraded
→ 10 秒后工位 Critical
```

验收断言：

- PrimaryCandidate = N-MOTOR；
- SupportingEventCount = 3；
- 到工位传播深度 = 2；
- 重复请求 `inserted=false`；
- SQL Graph=1、Analysis=1；
- Confirmed 与 Supplemented 两条 Review Journal 均保留；
- Host 重启后候选、路径和最新复核状态可查询。

## 9. 人工复核验收

- Confirmed 只能选择推断候选；
- Rejected 不选择节点；
- Supplemented 必须选择已审批图节点并填写说明；
- Review 不修改 GraphVersion 或 GraphHash；
- Review 不删除原始 Candidates 和 Paths；
- Review 不触发 PLC、停机或调度操作；
- 生产 Actor 应来自认证身份，Body Actor 仅用于当前无统一身份接入的兼容场景。

## 10. 安全边界

测试必须确认：

- `AssetHealthRootCause.Enabled=false` 为默认；
- Production 默认关闭且 Nodes/Edges 为空；
- 无 PLC 写接口；
- 无设备停止接口；
- 无任务取消接口；
- 无路线、路权或派单修改；
- 无自动图更新；
- 无生成式 AI 拓扑推断；
- SQL 故障不阻塞控制链路。

## 11. 回退验证

AssetHealthRootCause__Enabled=false

关闭后停止新增分析，保留 SQL 图、分析和复核记录；v3.5、v3.4、Fusion、PLC 和调度继续运行。
